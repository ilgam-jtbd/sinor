# sinor — 시놀 분석 전용 리포지토리

> **이 저장소에서는 실 개발을 하지 않습니다.** 시놀(주) 전 서비스(시놀·시럽·시럽인연·시놀트립 등)의
> 전략 문서 학습, 기술 스택 실사, 분석 산출물 관리 전용입니다.

## 구조

```
docs/
├── 00_문서학습_지식베이스.md      # 전략·기획 문서 4종 학습 요약 (분석의 공통 전제)
├── 01_기술스택_실사_실행설계.md   # CC 기반 기술 스택 실사 실행 설계 (환경·순서·도구)
├── prompts/
│   └── CC_기술스택_정밀조사_프롬프트_v2.md   # 실사 실행용 프롬프트 원문 (v2.0)
├── templates/
│   └── 기술스택_실사_보고서_템플릿.md        # 실사 결과 보고서 표준 양식
└── reports/                        # 실사 결과·분석 보고서 산출물 (날짜별)
```

## 원칙

- **읽기 전용 조사** — 프로덕션 변경·계정 생성·개인정보 조회 금지
- **근거 기반** — 모든 확정 항목에 근거(파일 경로·명령어·응답 헤더·캡처) 명시
- **신뢰도 4단계** — `확정 / 유력 / 추정 / 미확인` 표기
- 미확인 항목은 비워두지 않고 "미확인 — 확인 방법"을 기재
