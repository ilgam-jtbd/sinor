# Claude Code / Cowork 커스터마이징 프롬프트

이 폴더를 Claude에 올린 뒤, 아래를 첫 메시지로 붙여넣습니다.
`[대괄호]` 부분만 실제 값으로 바꾸면 됩니다.

---

이 폴더의 index.html은 시놀 운영보드(스케줄·QA 대시보드)야.
단일 HTML + Firebase RTDB/Auth + 바닐라 JS 구조이고, 시놀용 브랜딩·팀·서비스 구분은
이미 반영돼 있어. README_시놀_설정가이드.md 를 먼저 읽고 구조를 파악한 뒤 아래를 진행해줘.

1. Firebase 설정 교체:
   [Firebase 콘솔에서 복사한 firebaseConfig 붙여넣기]

2. TEAM 배열의 email을 실제 구글 로그인 계정으로 교체:
   [김민지 / ceo / 실제이메일]
   [신진영 / coo / 실제이메일]
   [최지영 / po / 실제이메일]
   [박희수 / design / 실제이메일]
   [시럽 매칭 관리자 / mgr_lead / 실제이메일]
   [시럽 매니저 / mgr_a, mgr_b / 실제이메일]  ← 실제 인원수에 맞게 조정

3. 관리자 비밀번호(admin1234)를 [원하는 비밀번호]로 변경.

4. (선택) 샘플_이슈_시딩.json 을 Firebase Realtime Database에 가져오기 하면
   실측 기반 이슈 12건이 등록된 상태로 시작할 수 있어. 가져오는 방법을 알려줘.

작업 규칙:
- 수정 전 원본을 versions/ 폴더에 백업하고 시작
- 수정 후 인라인 스크립트 문법 검증(node --check)까지 하고 결과 알려줘
- Firebase 규칙은 firebase_rules.json 그대로 게시하면 된다고 안내
- 완료되면 로컬 테스트 방법(python3 -m http.server + ?env=staging)을 알려줘
- 회원 개인정보·서버 시크릿은 어떤 파일에도 넣지 마

## 대시보드 기능

- 스케줄(Gantt, 드래그 일정조정) / 프로젝트(우선순위 점수, 다중 Task) / 이슈(템플릿, 필터 저장, 첨부, @멘션) / 배포(번들, 환경태그, 공유링크) / 팀(멤버별 보드) / 개요(주간 브리핑)
- 권한: 읽기·쓰기·관리자 3단계, 신규 접속자 자동 등록(읽기)
- 전역 검색 Ctrl+K, 공유링크(?issue= ?deploy= #project=)
- 테스트베드: ?env=staging (운영 데이터와 완전 분리)
- 미디어: Cloudinary 무료 연동 시 100MB 원본 화질
