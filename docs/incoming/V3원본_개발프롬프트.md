# 시놀 V3 통합 개편 — Codex / Claude Code 작업 프롬프트

## 역할
당신은 시놀 앱·웹의 Senior Product Engineer이다. 첨부된 V3 전략과 기획서를 기준으로 기존 기능을 최대한 재사용하면서 IA, 화면, 이벤트, 전환을 수정한다.

## 절대 원칙
1. 기존 API/DB/인증/결제 기능을 먼저 조사하고 새로 만들지 않는다.
2. 데이터 근거가 없는 기능은 구현하지 말고 TODO로 표시한다.
3. 시니어 사용성을 최우선: 한글 명확한 메뉴, 최소 17px 본문, 48px 터치 영역, 짧은 문장.
4. 기존 SEO 색인 URL을 함부로 변경하지 않는다. 변경 시 301/캐노니컬/사이트맵 영향을 점검한다.
5. 결제·상담·신청은 실제 완료 이벤트까지 추적한다.
6. 모든 작업은 작은 커밋 단위로 수행하고 변경 파일/이유/검증 결과를 보고한다.

## 1. 핵심 IA 변경
기존 하단:
- 모임
- 라운지
- +
- 채팅
- 마이

TO-BE:
- 홈
- 여행
- 만남
- 모임

개인 설정은 우측 상단 `마이페이지`로 이동한다.

### 마이페이지
프로필 / 관심사 / 지역 / 본인인증 / 내 모임 / 포인트 / 결제·구독 / 알림 / 고객센터 / 약관 / 로그아웃

### 채팅
하단 1차 메뉴에서 제거한다.
- 모임 상세 → 모임 대화
- 상대 프로필 → 1:1 대화
- 헤더 메시지 아이콘 → 전체 대화
기존 `모임 / 1:1 대화` 2탭과 읽지 않음 규칙은 유지한다.

## 2. 앱 홈
기존 9섹션을 폐기하지 말고 다음 목적형 구조로 재배치한다.
1. 오늘의 추천
2. 빠른 메뉴: 여행 / 만남 / 모임
3. 단체미팅
4. 인연진단
5. 이번 주 여행
6. 내 지역 모임
7. 새로 열린 모임
8. 칼럼/정보
9. 공지/알림

수익 카드는 광고 배너처럼 보이지 않게 콘텐츠 카드와 동일한 컴포넌트를 사용한다.

## 3. 여행
시놀트립 멤버십을 중심으로 한다.
- 실제 가격/API 연동
- 정가 vs 멤버십가
- 일정/혜택/후기
- 하나투어는 판매상품이 아니라 광고 성과 측정 대상으로 취급

## 4. 만남
세 가지 목적을 명확히 분리한다.
- 시럽: 친구/관심사 기반 50+ 만남
- 시럽인연: 진지한 인연/전문 매니저/상담
- 단체미팅: 일정·지역·잔여석 기반 자연스러운 만남

시럽인연은 `인연 진단 → 상담 예약 → 전화`를 최단 경로로 구현한다.

## 5. 모임
기존 시놀 커뮤니티 기능을 유지한다.
카테고리: 지역 / 운동 / 여행 / 문화 / 취미 등.
카테고리 아이콘에는 반드시 한글 라벨을 붙인다.

## 6. 웹
기존 URL을 재사용한다.
- /meeting
- /information
- /download
- /silove
- /silovematch

`/silovematch-consult`는 광고 직행 랜딩으로 사용하지 않는다. 소개/신뢰 블록 후 상담으로 유도한다.

## 7. 웹 CTA 규칙
페이지별 목표를 하나만 둔다.
- 칼럼: 앱 설치
- 단체미팅: 웹 신청 완료
- 시럽인연: 전화 상담
- 여행: 멤버십 결제
- 자녀 콘텐츠: 카카오/문자 공유
- 시럽: 시럽 앱 설치

## 9. Codex/Claude Code 실행 절차
### Phase 0 — 조사
- repo 구조
- routing
- navigation component
- auth
- API
- analytics
- payment
- admin configuration
을 먼저 읽고 `IMPLEMENTATION_PLAN.md` 작성.

### Phase 1 — 안전한 IA
- 4대 메뉴 컴포넌트 구현
- 기존 화면 route 재사용
- 마이페이지 이동
- 채팅 deep-link 유지

### Phase 2 — 홈
- 기존 9섹션 데이터를 목적형 섹션으로 재배치
- 서버 제어 가능한 순서/ON-OFF 구조 확인
- 하드코딩 가격 금지

### Phase 3 — 만남/여행
- 기존 시럽/시럽인연/단체미팅/트립 URL과 기능을 연결
- 실제 CTA와 이벤트 부착

### Phase 4 — 웹
- 기존 URL 보존
- 스마트 앱 링크
- 칼럼 CTA
- /meeting 연결
- SEO/GEO/AEO metadata 및 schema 점검

### Phase 5 — 검증
- 모바일 360/390/430px
- iOS/Android
- 로그인/비로그인
- 빈 상태
- 네트워크 지연
- 결제 완료
- 이벤트 중복 여부
를 테스트한다.

## Claude Code 첫 실행 예시
다음 명령으로 시작한다.

"현재 저장소를 먼저 읽고 코드를 수정하지 마라.
시놀 V3 기획의 핵심은 하단 메뉴를 홈/여행/만남/모임 4개로 단순화하고 개인 설정을 우측 마이페이지로 이동하는 것이다.
먼저 현재 navigation, routing, home composition, chat, mypage, analytics, API 구조를 조사하라.
기존 기능을 재사용할 수 있는지 확인하고 IMPLEMENTATION_PLAN.md를 작성하라.
특히 기존 9개 홈 섹션과 채팅 2탭이 어떤 컴포넌트/API에서 구현되는지 파일 경로와 함께 표로 정리하라.
계획 승인 전에는 코드를 수정하지 마라."

## Claude Code 2차 실행 예시
"IMPLEMENTATION_PLAN.md를 기준으로 Phase 1만 구현하라.
새로운 API를 만들지 말고 기존 route/component를 재사용하라.
하단 navigation을 홈/여행/만남/모임으로 변경하고 마이페이지는 우측 상단으로 이동한다.
채팅은 기존 데이터와 대화방을 유지하면서 모임 상세/프로필/헤더에서 진입 가능하게 한다.
primary_nav_tap과 mypage_open 이벤트를 추가한다.
빌드와 테스트를 실행하고 변경 파일과 결과를 보고하라."
