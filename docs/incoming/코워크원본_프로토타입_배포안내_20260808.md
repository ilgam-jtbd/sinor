# 시놀 프로토타입 실물 반영본 — CC 배포 안내

## 무엇이 바뀌었나 (CC index.html 대비)

CC가 만든 index.html을 **베이스로 유지**하고, 브라우저 실물 분석 + 그로스/SEO 관점을 반영했습니다.
CSS 토큰·컴포넌트·브리프 레이어·앱/웹 토글·4탭 IA·이벤트 명세는 **그대로 유지**했습니다.

### 반영 1 — 실제 시놀/시럽/시럽인연 콘텐츠 (2026-08-08 브라우저 확인)

| 위치 | 변경 후(실제 확인) |
|---|---|
| 시럽인연 | **더 늦기 전에 시작하는 끝사랑** / 회원 46,366·매칭 9,273+·만족 45% |
| 시럽 | **老맨스가 필요할 땐?** / 위치기반·관심사·거리연령·연락처 차단 |
| 단체미팅 | **시놀 50+ 추억의 단체미팅** / 중앙일보 보도·6:6·국내 최초 |
| 신뢰 | **중소벤처기업부 장관 표창(2025.11)** 추가 |

### 반영 2 — 참조 사이트 우측 기획 주석 패턴

프로토타입을 `.protogrid` 2단으로: 왼쪽 실제 화면 + 오른쪽 [화면 보는 법 · ⚠️확인 필요 이슈 · 번호 기획주석 ①~④ · 기대 결과].

### 반영 3 (신규) — 그로스 · 검색 전략 SEO/ASO/AEO/GEO

**히어로 실측 티커** — 검색 4,232명·단체미팅 12.0%·AI유입 61명·칼럼 191편이 3.2초 회전.

**검색·발견 채널 전략 섹션(#channels)** — 4개 채널을 진단/실행/담당으로:
- SEO(주의): 제목에 검색어 삽입·칼럼 191편 내부링크·sitemap
- ASO(위험): App Store 한국어 등록·Play 데이터 안전 재제출·첫 스크린샷
- AEO(기회): FAQPage JSON-LD·질문형 헤딩
- GEO(주의): robots.txt AI크롤러 허용·llms.txt

**웹 프로토에 FAQ 블록 + 실제 FAQPage/Organization JSON-LD** 부착 — AEO가 말이 아니라 실물임을 증명.

### 반영 4 — 올바른 SEO 위생

이 브리프 문서 자체는 **내부 대외비**이므로 `<meta name="robots" content="noindex,nofollow">` 처리.
SEO/AEO/GEO 실행 대상은 문서가 아니라 **실서비스(sinor.co.kr·스토어)**임을 섹션에 명시.
og 공유 태그는 사내 공유용으로만 추가.

## 배포 방법 (CC 세션에서)

```
1. 시놀_화면목업_프로토타입_실물반영.html → prototype/index.html 교체
2. git add prototype/index.html
   git commit -m "프로토타입: 실제 콘텐츠 + 우측 기획주석 + 그로스/SEO·ASO·AEO·GEO 채널 전략 + FAQ JSON-LD"
3. git push
4. Pages 확인
```

## 실제 시놀 이미지 반영 (2026-08-08 브라우저 수집)

시럽인연(sinor.co.kr/silovematch)에서 실제 콘텐츠 이미지를 수집해 반영했습니다.
imweb CDN이 **외부 hotlink를 허용**함을 확인(img 태그 로드 OK, 1536px)하고 직접 사용했습니다.

| 위치 | 실제 이미지 |
|---|---|
| 만남 탭 3장 그리드 | 철저한 신원 인증 · 전문 매니저 1:1 · 다양한 미팅 파티 |
| 홈·만남·웹 단체미팅 카드 | 미팅 파티 이미지 |

- 모든 이미지에 `onerror` 폴백(unsplash) 유지 — CDN 정책이 바뀌어도 화면이 깨지지 않음.
- 이미지 URL은 실서비스 CDN 직접 참조. **더 안정적으로 하려면** CC가 저장소 `prototype/img/`에 다운로드해 로컬 경로로 교체 권장(hotlink 차단 리스크 제거).

## 실제 앱 화면 반영 (2026-08 스크린샷)

사용자가 제공한 실제 시놀 앱 화면(홈·내 모임·스토리)을 반영했습니다.

**핵심 발견 — 실제 앱은 5탭**: 홈 · 내 모임 · 스토리 · 대화방 · 내정보.
V3는 목적형 4탭(홈·여행·만남·모임)이라 확인 이슈 박스에 AS-IS 5탭 vs V3 4탭을 명시했습니다.
(사용자 결정: **V3 4탭 유지**, 실제 콘텐츠로만 보강)

**대표님 요구 — 대화 모임/1:1 분리**를 만남 탭에 반영:
- 대화 상단 2탭(모임 / 1:1 대화), 안 읽음은 탭에 점(dot)으로 표시.
- 모임 탭: 강남 아침 산책·시놀트립 마포구·5학년 사랑방
- 1:1 탭: 시럽인연 매니저·상대 회원

**실제 모임 데이터 반영**:
- 내 가입 모임: 5학년 사랑방(자동 가입)·시놀트립(마포구 1,672명·8/30 영종도)·CLUB NO.1(서초구 128명·8/12 정모)
- 주제별 모임: 친목 모임(인생을 재밌게)·취미 배움 모임(인생을 알차게)
- 홈 일정: 서울둘레길 트레킹(8/9 양재시민의숲역)

CC 참고: 스토리(글) 탭은 V3에서 모임으로 흡수. 실제 스토리 구조(전체·학년별·인기 글)를 살리려면 모임 하위에 글 탭 추가 검토.

## 대화방 확장 — 여행·단체미팅 통합 (리텐션 엔진)

대표 제안(여행 단체·단체미팅에도 대화방 적용, 운영 공지 활용)을 반영했습니다.

**설계 판단: 모임 탭 하위 구분 (별도 탭 신설 안 함)** — 리텐션 근거:
- 대화 탭을 늘리면 알림이 분산됨 → 모임/1:1 2탭 유지가 DAU에 유리.
- 여행·미팅을 모임 탭에 통합하고 하위 필터 칩(전체·취미모임·여행·단체미팅)으로 구분.
- 안 읽은 게 하나만 떠도 들어오게 → 조용한 여행 방도 활발한 취미 방에 얹혀 노출.

**구현**:
- 필터 칩 4종 + 방 성격 뱃지(취미·✈️여행·🍷미팅)로 공지형/수다형 시각 구분.
- 여행·미팅 방에 [운영 공지] 프리픽스(출발 안내·집결·드레스코드·후기 이벤트).
- 필터 클릭 시 해당 성격 방만 표시(JS 동작 확인 완료).

**비즈니스 임팩트** (기획주석 5번):
- 여행 전 공지 → 노쇼 감소 / 여행 후 사진·후기 → 재신청(LTV↑)
- 단체미팅 후 "오늘 어떠셨나요" → 시럽인연 1:1 상담 전환(수익 동선)
- 일회성 결제(여행·미팅)를 지속 관계로 전환 = V3 "발견→완수→리텐션" 완성

CC 참고: 운영자용 공지 발송 UI(방장·운영자 권한)와 공지 고정(pin) 기능은 실개발 시 추가 검토.

## 진단 정본 대조 (2026-08-06 진단 엑셀과 정합화 완료)

프로토타입 채널 섹션을 진단 정본과 대조해 아래를 교정했습니다.

| 채널 | 진단 정본 | 교정 전 | 교정 후 |
|---|---|---|---|
| AEO | **양호** | 기회(오류) | **양호** — 이미 FAQ 있음, 스키마만 |
| SEO | 주의 | 주의 | 시럽인연 조회 6,585·45% 추가 |
| GEO | 주의 | 주의 | AI유입 세부(챗GPT 47 등)·언론 인용 추가 |
| ASO | 위험 | 위험 | 일치 |

- AEO를 "기회"로 잘못 표기했던 것을 "양호"로 수정 — "아직 안 됨"이 아니라 "거의 다 됨, 표시만"이 정확한 판정.
