시놀 앱 홈 화면 기획서 V3.0
시놀 내부 기획 문서 · V3 개편안 · 2026.08.09
핵심 변경: 기존 '모임 중심 + 라운지 + 채팅 + 마이' 구조를 시니어가 한 번에 이해하는 생활 목적형 4대 메뉴 '홈 / 여행 / 만남 / 모임'으로 재정의하고, 개인 설정은 우측 상단 '마이페이지'로 통합한다.
1. V3 전략과 UX 방향
시놀의 전략은 커뮤니티를 버리는 것이 아니라 '입구'로 유지하면서 시럽인연·단체미팅·시놀트립을 수익 동선으로 연결하는 것이다.
현재 전략 문서의 핵심 TO-BE는 홈에서 단체미팅·인연 진단·이번 주 여행을 추천 카드로 노출하고, 단일 계정과 측정을 연결하는 것이다.
기존 목업의 9섹션 자체는 유효하지만, 하단 5개 메뉴(모임/라운지/+/채팅/마이)는 시니어 관점에서 서비스 목적이 분산되어 있다.
따라서 '기능명'보다 '내가 무엇을 하러 왔는가'를 기준으로 4개 대메뉴를 만든다.
2. 권고 IA — 4대 메뉴
| 대메뉴 | 사용자 질문 | 핵심 콘텐츠 | 수익 연결 |
| 홈 | 오늘 뭐가 있지? | 오늘 추천, 내 지역, 인기 모임, 추천 콘텐츠, 공지 | 단체미팅/인연진단/여행 카드 |
| 여행 | 어디 갈까? | 시놀트립, 여행 일정, 멤버십 혜택, 여행 후기 | 연 49,900원 멤버십 |
| 만남 | 누구를 만날까? | 시럽, 시럽인연, 인연진단, 단체미팅 | 시럽인연 상담/단체미팅 |
| 모임 | 무엇을 같이 할까? | 취미/동호회, 지역 모임, 새 모임, 모임 개설 | 커뮤니티 활동→재방문/전환 |
3. 상단/우측 개인 설정
상단 우측: '마이페이지' 텍스트 + 사람 아이콘. '마이' 단독 메뉴명은 사용하지 않는다.
마이페이지: 프로필, 관심사, 지역, 알림, 본인인증, 포인트, 결제/구독, 내 모임, 고객센터, 약관/개인정보, 로그아웃.
개인 설정은 서비스 탐색 메뉴와 분리한다. 사용자는 여행/만남/모임을 탐색하다가 설정 때문에 현재 맥락을 잃지 않는다.
4. 홈 화면 TO-BE
| 순서 | 영역 | 설계 |
| 1 | 헤더 | 시놀 로고/지역 + 우측 마이페이지 |
| 2 | 오늘의 추천 | '오늘 시놀에서 해볼 것' 3~4개 |
| 3 | 빠른 메뉴 | 여행 / 만남 / 모임 / 내 지역 모임 |
| 4 | 수익 카드 | 단체미팅 / 인연진단 / 이번 주 여행 — 콘텐츠와 같은 카드 위계 |
| 5 | 내 지역 모임 | 지역 기반 최신/인기 모임 |
| 6 | 새로 열린 모임 | 최신 10개, 잔여석/현재 인원 |
| 7 | 칼럼/정보 | 관심사별 콘텐츠 → 모임/여행/만남 연결 |
| 8 | 공지/알림 | 운영 공지와 개인 알림 |
5. 4대 메뉴 상세
홈
개인화된 오늘의 발견이 중심. 검색창은 유지하되 '무엇을 찾으세요?'로 단순화.
광고처럼 보이는 전면 배너보다 추천 카드 중심.
여행
현재 판매 상품은 시놀트립 멤버십 중심. 정가/멤버십가 비교와 일정/혜택을 명확히 표시.
하나투어는 판매 콘텐츠가 아니라 광고 성과 측정 지면으로 분리.
만남
시럽과 시럽인연을 같은 목적 아래 보여주되 차이를 명확히 한다: '친구/가벼운 만남' vs '진지한 인연'.
인연진단 → 상담 예약 → 전화 상담을 최단 경로로 제공. 단체미팅은 일정/잔여석 중심.
모임
기존 시놀의 핵심 자산을 그대로 유지: 취미·운동·여행·문화·지역 소모임.
카테고리는 아이콘+한글 라벨, 최소 17px, 터치 영역 48px 이상.
6. 채팅의 위치
채팅을 하단 대메뉴에서 제거하고, 각 맥락 안에서 진입한다.
모임 상세 → '모임 대화', 상대 프로필/만남 → '1:1 대화'.
전체 메시지는 마이페이지 또는 헤더 알림/메시지 아이콘에서 접근할 수 있다.
기존 '모임/1:1 대화' 2탭 구조는 유지한다. 기존 문서의 채팅 설계는 기능적으로 유효하다.
7. 데이터/콘텐츠 충분성 판단
현재 콘텐츠는 4대 메뉴를 구성하기에 충분하다. Google Play 설명에도 지역 친구, 등산·여행·운동·문화 모임, 모임 개설 등의 핵심 콘텐츠가 확인된다.
웹에는 시럽인연의 신원인증·전문 매니저·단체미팅·회원분포·후기·FAQ·상담 흐름이 충분히 존재한다.
따라서 1차 개편은 콘텐츠를 새로 만드는 것보다 기존 콘텐츠를 4대 메뉴에 재배치하고 연결하는 것이 우선이다.
부족한 것은 '콘텐츠 양'보다 '콘텐츠 간 연결'이다: 모임→만남, 여행→모임, 칼럼→앱 설치/지역 모임, 만남→상담.
8. KPI/이벤트
기존 KPI 유지: DAU/MAU, 홈 섹션 노출/탭, 검색 이용률, 단체미팅 신청, 인연진단 완료, 상담전화, 여행 멤버십 조회/구매.
신규: primary_nav_tap(menu=home|travel|meet|groups), mypage_open, chat_entry(source), recommendation_card_tap.
