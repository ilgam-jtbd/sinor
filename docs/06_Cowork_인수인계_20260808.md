## 2. 발견 — 판단을 바꾸는 것들

### 2-1. 개발요구서 URL 판정 3건이 실제와 다릅니다 ★

| 개발요구서 v1.0 | 실제 (2026-08-08 확인) | 공수 변화 |
|---|---|---|
| 단체미팅 — **독립 URL 없음**(홈 앵커) | **`/meeting` 존재** · 색인됨 | 신설(3주) → **연결·측정·광고 이관(3일)** |
| 칼럼 — 경로 미확인 | **`/information`** (상세 `?bmode=view&idx=`) | 하단 카드 즉시 착수 가능 |
| 앱 다운로드 — 경로 미확인 | **`/download`** | 스마트 링크 교체 대상 확정 |

**추가 확인** — `/adv`(앱 광고상품 페이지가 **이미 존재**), `/jeju`(켄싱턴 제휴), `/moim`, `/silovematch_event`, `/company`, `web.sinor.co.kr`(서브도메인, 용도 미확인).

**의미** — 웹 개편은 신규 개발이 아니라 **이미 있는 페이지를 잇고 측정을 붙이는 일**입니다. 종합전략 v3의 "새로 만들 것보다 이어붙일 것이 많다"가 URL 층위에서도 그대로 맞습니다. **개발요구서 v1.1에서 4.2 충돌②와 Q4를 수정해야 합니다.**

**남은 확인** — 부사장님이 주신 경로는 앵커(`#doz_menu_meeting`)인데 검색에는 `/meeting`이 색인돼 있습니다. **페이지는 있는데 사이트 메뉴가 앵커라 연결이 안 된 상태**로 보이며, 그렇다면 메뉴 링크만 바꾸면 되는 일입니다. 개발 회신 D9.

### 2-2. 웹 플랫폼은 아임웹(Imweb)으로 유력 — Q7 최악 시나리오 회피

근거는 두 가지입니다. 칼럼 상세 URL의 `?bmode=view&idx=` 가 아임웹 게시판 규격이고, 요소 식별자 `doz_` 접두도 아임웹 전신(DOZ)의 흔적입니다.

사실이면 **`<head>` 커스텀 코드 삽입·페이지별 메타 지정·GTM 설치가 가능**합니다. A군 요구사항(스마트 배너·전환 스크립트·스키마) 대부분이 살아 있습니다. 개발자에게 **"아임웹 맞는지, 코드 삽입 권한이 사내에 있는지"** 두 줄만 물으면 확정됩니다. (현재 신뢰도: 유력)

### 2-3. 단체미팅 구독 가격이 성립하지 않습니다 ★

참가비가 **99,000 ~ 300,000원(3배 편차)**로 확인됐습니다. v3 S9의 「단품 2회 값 ≈ 구독 3개월」을 그대로 적용하면 —

| 기준 단품가 | 구독 3개월 환산 | 월 구독료 |
|---|---|---|
| 99,000원 | 198,000원 | **66,000원** |
| 300,000원 | 600,000원 | **200,000원** |

**월 66,000원도 시니어 구독료로는 높고 200,000원은 성립하지 않습니다.**

**권고** — 구독은 **기본 참석권(도심 당일형, 99,000원대)** 월 1회 + 우선 예약 + 이월만 커버하고, 1박 2일 글램핑·나트랑 미팅여행은 **구독자 할인율**로 연결합니다. 그러면 구독료가 월 3만원대로 내려가고 고가 상품이 업셀 경로가 됩니다.

**이건 원칙을 뒤집는 게 아니라 실제 가격표에 대입했을 때 나오는 구체화입니다.** 사업 확정 필요.

### 2-4. 시럽인연의 차별점은 가격대가 아니라 「성혼비 없음」입니다 ★

| 구분 | 시장 |
|---|---|
| 일반 가입비 | 200~500만원 |
| 노블레스 | 300~500만원 |
| VIP | 1,000~3,000만원 |
| 50대 재혼 | 1,000만원 이상 견적 사례 |
| **성혼비(성공 보수)** | **별도 100~500만원 추가** |

시럽인연 300~400만원은 **가격대만 보면 시장 중간**입니다. 「경쟁사 대비 절반」은 노블레스~VIP와 비교할 때만 성립합니다.

**진짜 차별점은 성혼비 없는 총액 완결**이며, 실질 부담이 40~60% 낮습니다.

**실행 3가지** — ① 상담 랜딩 신뢰 블록 **첫 줄을 「성혼비 없음」으로** ② **총액 비교표**를 콘텐츠로 제작 ③ FAQPage 스키마로 AEO 대응. 이탈 7.0%인 상담 페이지에 붙일 수 있는 가장 강한 자산입니다.

### 2-5. ASO — 스토어 제목에 검색어가 없습니다

| 앱 | 현재 Play 제목 |
|---|---|
| 시놀 | `시놀 - 50+ 친구만들기&모임 취미 동호회` |
| 시럽 | `시럽 - 중장년 안심 데이트 & 이성 만남 앱` |

'50+'는 회사가 쓰는 말이고 사용자는 **'5060' '중년' '시니어'**로 검색합니다. GA4에서 유입을 만든 키워드군이 시놀 앱 제목에 하나도 없습니다. **스토어 콘솔 접근만 있으면 하루 작업입니다.**

### 2-6. 경쟁 지형 — 당근 모임이 구조적 최대 위협

| 경쟁자 | 위협 | 판단 |
|---|---|---|
| **당근 모임** | **최상** | CAC 사실상 0 · 지역 밀도 압도. 「지역 모임」으로 정면 경쟁하면 집니다 |
| 오이 | 상 | 4060 취미모임 동일 세그먼트. 채팅 탭 구조의 참고 대상이기도 함 |
| 문토 | 중 | 관심사 커뮤니티, 주 타깃은 더 젊음 |
| 러브캐스팅 | 중 | 단체미팅 직접 경쟁 |
| 포페런츠 | 중 | **자녀 타깃 직접 경쟁자** — 이탈 7.7% 최저 구간인데 시놀은 글이 1편뿐 |

커뮤니티 층에서 싸우는 것은 비용 경쟁입니다. 이기는 층은 매칭이며, **「입구-전환-확장」 구조가 경쟁 지형에서도 맞습니다.**

### 2-7. 회사 맥락 — 외부에서 보이는 시놀

2023.03 설립 · 대표 김민지 · 시드 5억(파인드어스 등) 후 **프리시리즈A 6억 진행** · 회원 3만(런칭 1년) → 7만여명(2024.09) → 10.7만(2026.07) · **초기 획득은 등산로 입구·찜질방 오프라인 모객** · 50플러스센터·대한노인회 MOU · 2026 국가 R&D(멀티에이전트·자연어처리·중장년 맞춤형).

**주목** — 오프라인 모객이 초기 성장의 실제 엔진이었다면, **가입 CAC 2,836원을 외부 문서에 쓸 때 획득 채널 구성을 함께 밝혀야** 방어가 됩니다.

### 2-8. 일본 벤치마킹 — 마리슈의 리본 마크

핵심은 **본인이 스스로 다는 배지**라는 점입니다. 시스템이 이혼·사별을 표시하면 **낙인**, 본인이 달면 **신호**입니다. 이 한 끗이 전부입니다.

**시놀 적용안 — 「공감 배지」 3종**: 재혼 이해 / 자녀 이해 / **사별 공감**. 사별을 넣은 것은 5060에서 이혼보다 사별 비중이 커 일본과 다른 지점이기 때문입니다. 문구·범위는 CX 검토가 필요해 **MVP에서 제외하고 2단계로** 미뤘습니다.

일본 5대 트렌드 중 시놀이 **지금** 손댈 것은 ③ 중장년 매칭과 ⑤ 테마 커뮤니티 여행뿐입니다. 슈카츠·돌봄테크·인재파견은 T1 흑자 전환 후입니다.
