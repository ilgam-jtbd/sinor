# 시놀 자산 대장 — 2026-08 (v1.10 · 인벤토리 트랙 CLOSED 2026-08-30, 유지 갱신 중)

> **CLOSED + 유지 갱신** — 최초 자산 인벤토리 트랙(코워크 1~4차 + 시나리오 A 확정)은 2026-08-30 종결됐습니다. 이 대장은 그 이후로도 **유지 문서**로서 새 자산·위치 변경·플래그 변동이 생길 때마다 계속 갱신됩니다(버전 번호는 하단 갱신 이력 기준).

> **역할** — 코워크·CC·배포 페이지에 흩어진 문서 자산의 **위치와 상태를 가리키는 지도**입니다. 문서 최종본의 소유는 각 위치에 남고, 이 대장은 "어디 있고, 지금 믿어도 되는지"만 답합니다.
> **근거** — 코워크 자산 대장 회신 1·2차(v1.2)·3차(2026-08-30) + CC 배포 이력.
> **파일 유통 체계 확정(2026-08-31)** — **내부공유(md·비민감) = 공개 repo 링크 / 대외비 원본 = 🔒 sinor-vault(비공개)만.** 링크는 허브·대장에 노출해도 안전(비권한자 404). 예외 2가지: ① **러닝스푼즈 W1~W4 = 외부 저작물, 재배포 금지 — 어느 git에도 미게시**(CC 수신 채널 보유) ② **회원 데이터 = git 전면 금지**(아래 행).
> **⚠ 플래그 원칙** — 낡은 수치가 그대로 인용되는 것이 이 대장의 최대 위험입니다. 플래그가 붙은 문서는 **정본 대사 없이 단독 인용 금지.**
> **패치 베이스 규칙(2026-08-30 확정, 코워크 3차 §3)** — 배포 중인 페이지(/learn/·/devops/ 등)에 대한 패치는 **항상 라이브 배포본을 fetch하여 그 위에** 만듭니다. outputs 사본은 이력 보존용이며 패치 베이스로 쓰지 않습니다. 패치 전달 시 "베이스: gh-pages <해시>"를 명기합니다.
> **정본 이중 관리(단방향)** — 코워크 outputs 정본 = **마스터**, repo `docs/03` = **공개용 축약 미러**. 수정은 항상 마스터에서 시작하고 repo는 따라갑니다(역방향 편집 금지).
