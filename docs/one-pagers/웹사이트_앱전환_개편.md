## 2. 푸는 문제

웹은 28일간 **5,750명**을 데려옵니다. 그중 57%가 검색에서 오고, 칼럼 191편이 그 엔진입니다. 그런데 —

- 앱 다운로드 페이지 도달 **79명 (1.4%)**
- 7개월간 결제 기록 **20건**
- 첫 방문자 **93%** — 재방문 장치가 없음

**트래픽은 있는데 앱으로도 결제로도 이어지지 않습니다.**

## 3. Four Customer Questions

**1. 즉시적인 고객은 누구인가?**

**2. Customer Job은?**
5060 본인: "내 또래가 있는 곳을 확인하고 안전한지 판단하는 것."
4050 자녀: "부모님께 부담 없이 권할 방법을 찾는 것."

| 글 주제 | 하단 카드 목적지 | 근거 |
|---|---|---|
| 건강·운동 (맨발걷기 등) | 앱 설치 — 취미 모임 | 이탈 9.1% 최저군 |
| 모임·취미 | 앱 설치 — 지역 모임 | 모객 지면 |
| 재혼·황혼재혼 | **시럽인연 상담 예약** | 상담 이탈 7.0% |
| 자녀·부모님 | **부모님께 보내기 (공유)** | 이탈 7.7% 최저 |
| 여행 | 시놀트립 멤버십 | 이탈 72.7% 개선 대상 |
| 정책·혜택 | 앱 설치 — 정보 알림 | 조회 상위 유입 |

**운영 규칙** — 문구는 주제별 6종으로 관리하고 **어드민에서 매핑을 바꿀 수 있어야** 합니다. 관련 글은 같은 주제 묶음 안에서만 노출합니다(주제가 튀면 이탈).

### 5-3. `/meeting` — 신설이 아니라 보강

이미 존재하므로 작업은 **보강 + 연결 + 측정**입니다.

| # | 작업 | 근거 |
|---|---|---|
| 1 | 제목에 검색어 반영 — 「[지역] 5060 단체미팅」 | 「[부산·경남] 5060 단체미팅」이 이탈 11~18%로 효과 증명 |
| 2 | **신뢰 블록을 상단에** — 성혼비 없음 · 상담 무료 · 본인인증 · 후기 | 직행 랜딩 75.8% vs 내부 경유 7.0%의 차이가 이것 |
| 3 | 일정 목록 (날짜·지역·잔여석) · 참가 후기·사진 | 만남 상품에서 가장 강한 전환 요소 |
| 4 | FAQ + **FAQPage 스키마** | AEO 답변 노출 후보 — 본문은 이미 있고 표시만 붙이면 됨 |
| 5 | **광고 랜딩 이관** — 상담 폼 직행(75.8%) 예산을 이쪽으로 | 즉시 효과 |
| 6 | 지역 변형 `/meeting/seoul` 등 | 롱테일 확보 |
| 7 | 홈 앵커와의 관계 정리 | **중복 콘텐츠 여부 확인 필요** |

### 5-4. 자녀 타깃 `/family` — 설치 버튼을 넣지 않는 이유

이탈률 7.7%로 사이트 최저인데 **글이 1편뿐**입니다.

- **설치 주체가 다릅니다.** 읽는 사람은 4050 자녀, 쓸 사람은 60대 부모입니다. 자녀에게 설치시키면 그 계정은 사용되지 않고 부모에게는 아무것도 전달되지 않습니다
- CTA는 **카카오톡으로 부모님께 보내기 · 문자로 보내기 · 자녀가 대신 상담 예약하기**
- 상담 예약 폼에 **「부모님 정보로 신청」** 항목을 둡니다
- 콘텐츠를 **최소 4편으로 확장** — 부모님 재혼 / 부모님 앱 추천 / 부모님 혜택 / 부모님 친구 만들기

### 5-5. 여행 — 시놀트립 유료 멤버십에 집중

**정책 확정(2026-08-08)** — 여행에서 파는 것은 **시놀트립 멤버십(49,900원/년)** 하나입니다. 하나투어(`msinor.hanatour.com`)는 제휴 수수료 상품이 아니라 **광고 지면**으로 취급합니다.

이 구분이 작업 우선순위를 바꿉니다.

| 대상 | 성격 | 이번 개편에서 |
|---|---|---|
| **시놀트립 멤버십** | 자사 유료 상품 | **판매 동선 신설이 목표.** 정가 vs 멤버십가 · 예약 CTA · 결제 완결 |
| 하나투어 27p | 광고 지면 | 판매 대상 아님. **광고 성과 측정**(노출·클릭)만 붙입니다 |

**시놀트립 판매 동선 — 실행 5가지**

| # | 작업 |
|---|---|
| 1 | 상품 화면마다 **정가 vs 멤버십가 나란히** — 지금은 멤버십 가치가 그 화면에 없습니다 |
| 2 | **「멤버십 가입하고 예약」 원탭** + 전화 예약 번호. 지금은 보고 나갈 곳밖에 없습니다 |
| 3 | 결제 기본값 **카드로** — 무통장 7일 조건은 연 구독에 치명적입니다 |
| 4 | 시놀 도메인에 **지역 허브 5개**(강원·제주·경상·충청·전라). `/jeju`가 이미 있으므로 확장입니다 |
| 5 | 포인트 **11,100P 활용 — 「포인트로 첫 달」**이 가장 싼 구독 전환 장치입니다 |

**측정 함의 — 크로스도메인의 우선순위가 내려갑니다.** 하나투어가 광고 지면이면 그쪽 결제를 우리 `purchase`로 잡을 이유가 없습니다. 대신 **시놀트립 멤버십 결제**를 자사 도메인에서 완결시키고 그 지점에 `purchase`를 붙이는 것이 핵심입니다. Q9(하나투어 계약)도 수수료 구조가 아니라 **광고 단가와 지면 계약 조건** 확인으로 바뀝니다.

## 7. 성공지표와 가드레일

### 7-1. 성공지표

```
웹 기여 = 앱 설치 + 웹 완결 전환
앱 설치 = 웹 방문자 × 설치 유도 도달률 × 스토어 전환율
```

| 지표 | 현재 | 목표 (8주) |
|---|---|---|
| 앱 설치 유도 도달률 | 1.4% (79/5,750) | **5% 이상** (약 288명, 3.6배) |
| 웹 출처 앱 설치 수 | 미측정 | 측정 개시 자체가 1차 목표 |
| 단체미팅 웹 신청 | 미측정 | `/meeting` 측정 부착 후 기준선 확정 |
| 결제 완료 이벤트 기록률 | 20건 / 7개월 | 실제 결제 대비 **90% 이상** |
| **시놀트립 멤버십 판매** | 미측정 | 자사 결제 완결 후 기준선 확정 — 이번 개편의 여행 부문 유일 KPI |

### 7-2. 가드레일

| 지표 | 판정 |
|---|---|
| 시럽인연 상담 신청 수 | **감소 시 실패** — 앱 유도가 상담 흐름을 침범한 신호 |
| 단체미팅 신청 완료율 | **감소 시 실패** — 신청 도중 앱 유도가 끼어든 경우 |
| 페이지 로딩 시간 | 증가 시 경고 — 배너·스크립트 추가로 인한 지연은 시니어에게 치명적 |
| CS 문의 | 「앱 설치하라는 창이 계속 뜬다」 유형 별도 태깅 |

## 9. 시럽인연 상담 랜딩 — 「성혼비 없음」을 최상단으로

외부 실사에서 확인된 시장 관행입니다.

| 구분 | 시장 |
|---|---|
| 일반 가입비 | 200~500만원 |
| 노블레스 | 300~500만원 |
| VIP | 1,000~3,000만원 |
| 50대 재혼 | 1,000만원 이상 견적 사례 |
| **성혼비** | **별도 100~500만원 추가** |

시럽인연 300~400만원은 **가격대만 보면 시장 중간**입니다. 「경쟁사 대비 절반」은 노블레스~VIP와 비교할 때만 맞습니다.

**진짜 차별점은 총액 구조입니다.** 성혼비가 없으면 실질 부담이 40~60% 낮습니다.

**실행**
1. 신뢰 블록 **첫 줄을 「성혼비 없음」으로** 올립니다 — 지금은 여러 요소 중 하나로 묻혀 있습니다
2. **총액 비교표**를 콘텐츠로 만듭니다 (경쟁사 가입비+성혼비 vs 시럽인연 총액). 이탈 7.0% 페이지에 붙일 수 있는 가장 강한 자산
3. AEO — 「결혼정보회사 가격은?」 「재혼 비용 얼마인가요?」의 답이 그대로 이 표입니다. FAQPage 스키마로 구조화
