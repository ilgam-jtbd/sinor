## 2. Four Customer Questions

**1. 즉시적인 고객은 누구인가?**
앱을 열었지만 무엇을 볼지 정하지 못한 5060 회원. 이미 검색 의사를 보인 4,232명이 1차 대상입니다. 구매자와 사용자가 같습니다.

**2. Customer Job은 무엇인가?**
"오늘 참여할 곳을 고르는 것." 검색 기능을 쓰고 싶은 게 아닙니다. 그래서 성공은 검색 실행 횟수가 아니라 **모임 상세 도달과 신청**입니다.

**3. 10배 더 잘해야 하는 것은?**
**찾는 시간.** 경쟁 우위는 기능이 아니라 재고 1,561개입니다. 당근 모임·오이와 기능으로 싸우면 집니다. 그 재고에 닿는 시간을 줄이는 것이 유일한 10배 지점입니다.

### 3-2. 채팅 2탭

| 항목 | 규격 |
|---|---|
| 탭 명칭 | **① 모임 ② 1:1 대화** — 문토의 '그룹/개인' 대신 오이 방식. '모임'은 3년간 써온 자사 용어 |
| 기본 선택 | 모임 탭 (앱 대화량 대부분이 모임에서 발생) |
| 안 읽음 — 탭 | **점(dot)**. 숫자 뱃지 금지 — 미확인 개수가 쌓여 보이면 회피를 유발 |
| 안 읽음 — 목록 | 대화방별 **숫자**. 탭은 점, 목록은 숫자로 역할 분리 |
| 점 해제 시점 | **탭 진입이 아니라 대화방 실제 열람 시점.** 탭만 눌러도 사라지면 알림 신뢰도가 무너짐 |
| 스크롤 위치 | 탭 전환 시 각각 **독립 보존** |
| 탭 라벨 크기 | 선택·미선택 **동일 크기**. 굵기와 하단 인디케이터로만 구분 — 크기 변화는 화면 흔들림으로 인지 |
| 빈 상태 | 「아직 참여한 모임이 없어요」 + **[모임 둘러보기]** + 지역 모임 3개 추천. 현재는 「채팅 내역이 없어요」만 노출되어 다음 행동이 끊김 |

**빈 상태는 가장 값싼 전환 지점입니다.** 같은 패턴을 모임 목록·검색 결과 0건·알림 없음 화면에도 적용합니다.

## 4. 수익 카드 3종 설계

### 4-1. 공통 규칙 (위반 시 재작업)

- **콘텐츠 카드와 동일 컴포넌트**를 씁니다
- 테두리색·배경색·「광고」 표기 **금지**
- 3종 연속 배치 **금지**
- 가로 스크롤 카드는 다음 카드가 **약 20% 걸치게**

배너는 광고로 읽히고 카드는 추천으로 읽힙니다. 같은 트래픽에서 다른 전환율이 나오는 이유가 이것입니다.

### 4-2. 카드별 명세

| 카드 | 표시 정보 | 액션 | 특이 규칙 |
|---|---|---|---|
| 단체미팅 | 날짜 · 지역 · 잔여석 | [신청하기] | **잔여 3석 이하 시 강조 표기** — 정원 운영이 실제 희소재이므로 과장이 아님 |
| 인연 진단 | 3~5문항 간단 진단 | [내 유형 보기] | 결과 화면 CTA는 **전화 우선** |
| 이번 주 여행 | 정가 / 멤버십가 병기 | [멤버십가로 보기] | 가격은 **실제 상품과 연동**. 하드코딩 시 불일치 민원 |

### 4-3. 단체미팅 구독 — 가격 재설계 (신규)

외부 실사에서 참가비가 **99,000~300,000원(3배 편차)**로 확인됐습니다. v3 S9의 「단품 2회 값 ≈ 구독 3개월」을 그대로 적용하면 월 66,000~200,000원이 되어 시니어 구독료로 성립하지 않습니다.

**권고 설계**

| 구분 | 범위 | 가격 방향 |
|---|---|---|
| 구독 커버 | **기본 참석권**(도심 당일형, 99,000원대) 월 1회 + 우선 예약 + 미참석 시 다음 달 이월 | 월 3만원대 |
| 구독 제외 | 1박 2일 글램핑 · 나트랑 미팅여행 등 원가 상이 상품 | **구독자 할인율**로 연결 |

이렇게 하면 구독료가 시니어 수용 범위에 들어오고, 고가 상품이 구독자 업셀 경로가 됩니다.
**전제** — 결제 기본값이 무통장 입금인 한 정기결제가 원천 차단됩니다. **카드 결제 전환이 구독의 선행 조건입니다.**

### 4-4. 「공감 배지」 — 일본 마리슈 벤치마킹 (신규)

일본 재혼 매칭 앱 **마리슈(marrish)** 는 재혼·자녀 있는 회원을 이해한다는 표시로 **리본 마크**를 프로필에 답니다. 이혼·사별을 낙인이 아니라 **공감대로 전환**하는 UX 장치이며, 30~50대 재혼 시장에서 이 앱의 핵심 차별점입니다.

**시놀 적용안 — 프로필 「공감 배지」**

| 배지 | 의미 | 효과 |
|---|---|---|
| 재혼 이해 | 재혼을 긍정적으로 생각합니다 | 재혼 희망자가 눈치 보지 않고 검색 |
| 자녀 이해 | 자녀가 있어도 괜찮습니다 | 5060 재혼의 최대 허들 완화 |
| 사별 공감 | 사별 경험을 이해합니다 | 5060에서 이혼보다 사별 비중이 큼 |

**설계 원칙** — 배지는 **본인이 스스로 다는 것**이지, 시스템이 이혼·사별 여부를 표시하는 것이 아닙니다. 후자는 낙인이 되고 전자는 신호가 됩니다. 이 구분이 마리슈 방식의 핵심입니다.

배치: 프로필 · 모임 참가자 목록 · 단체미팅 신청 화면. 인연 진단 결과와 연결하면 시럽인연 상담 전환의 사전 필터가 됩니다.
(적용 범위·문구는 CX 검토 필요 — 신뢰도: 제안)

## 6. 컴포넌트·세션 관리 규격 — 운영자가 배포 없이 바꿀 수 있어야 합니다

개발 배포 없이 바꿀 수 있는 범위가 곧 **그로스 실험의 속도**입니다. 아래 8종은 전부 어드민에서 수정 가능해야 합니다.

| 컴포넌트 | 운영자 조작 | 측정 | 세션 처리 |
|---|---|---|---|
| 기획전 배너 | 이미지 · 링크 · 노출 기간 · 순서 | 노출 · 탭 | 세션당 첫 노출만 임프레션 집계 |
| 홈 섹션 순서 | **드래그로 순서 변경** · 노출 on/off | 섹션별 기여도 | 순서 변경은 즉시 반영, A/B 대상 |
| 수익 카드 3종 | 문구 · 목적지 · 노출 여부 | 노출 · 탭 · 전환 | 카드별 노출 빈도 상한 설정 가능 |
| 카테고리 아이콘 | 라벨 · 순서 · 노출 여부 | 탭 | — |
| 칼럼 하단 카드 | **주제별 매핑 6종** | 노출 · 설치 전환 | 동일 세션 재노출 제한 |
| 단체미팅 일정 | 일정 · 지역 · 정원 · 잔여석 | 조회 · 신청 | 잔여석 실시간 반영 |
| 앱 설치 바(웹) | 문구 · 노출 페이지 · 닫기 주기 | 노출 · 설치 | **닫기 이력 7일 저장** |
| 빈 상태 문구 | 문구 · 버튼 목적지 | 노출 · 탭 | — |

**세션 관리 원칙**
- 배너·설치 바의 **닫기 이력은 세션이 아니라 기기 단위로 7일** 저장합니다. 세션 단위면 재방문마다 다시 뜨고, 시니어 사용자는 이를 오류로 인지합니다
- 스마트 앱 배너와 하단 고정 바를 **동시 노출하지 않습니다**. 4주 운영 후 성과를 비교합니다
- 홈 섹션 노출 임프레션은 **세션당 1회**만 집계합니다. 스크롤 왕복으로 부풀려지면 기여도 판정이 왜곡됩니다

## 7. 성공지표와 가드레일

### 7-1. 지표 계층

```
매출     = 결제고객 × 객단가
결제고객 = MAU × 결제전환율
MAU      = f(신규유입, 재방문, 부활)
```

월 신규가 5,964명(2025.02) → 1,361명(2026.07). **신규로 MAU를 지키는 경로는 닫혔습니다.** 이 개편의 레버는 재방문입니다.

### 7-2. 성공지표

| 지표 | 현재 | 목표 | 판정 |
|---|---|---|---|
| DAU / MAU | 5.8% | **8% 이상** | 배포 후 8주 |
| 앱 내 검색 이용률 | 진입점 없음 | 홈 방문자 대비 **15% 이상** | 배포 후 8주 |
| 홈 → 모임상세 탭 전환율 | 미측정 | 4주 기준선 확정 후 목표 설정 | 4주 |
| 단체미팅 신청 (홈 카드 경유) | 미측정 | v3 90일 KPI에 직접 기여 | 8주 |
| 결제 완료율 | 미측정 (purchase 20건/7개월) | 측정 개시 자체가 1차 목표 | 8주 |

### 7-3. 가드레일 — 악화되면 성공지표가 좋아져도 실패

| 지표 | 판정 기준 |
|---|---|
| 모임 참여 후 이탈률 | 악화 시 실패 — 빈 모임·부실 모임 노출이 늘어난 신호 |
| 앱 실행 후 첫 액션까지 시간 | 증가 시 실패 — 화면이 복잡해진 신호. 섹션 축소 검토 |
| CS 문의 | 「화면이 바뀌어 못 찾겠다」 유형 별도 태깅, 배포 후 2주 집계 |

**성공지표 5종 중 3종, 가드레일 3종 전부가 현재 미측정입니다.** 측정 설정이 배포보다 먼저입니다.

## 8. 검증 설계 (A/B)

| 항목 | 설계 |
|---|---|
| 대상 | 홈 진입 사용자 |
| 분기 | 검색바 노출군 vs 미노출군 50:50 |
| 기간 | 2주 (DAU 2,130 기준 양군 각 2,000세션 확보 가능) |
| 1차 지표 | 홈 → 모임상세 탭 전환율 |
| 2차 지표 | 7일 재방문율 |
| 가드레일 | 첫 액션까지 시간 · 모임 참여 후 이탈률 |

**앱 버전 분기 A/B가 불가능한 경우** — 배포 전 4주 / 후 4주 비교로 대체하되, 그 기간 광고 집행을 고정합니다. 계절성·마케팅 변동이 섞이면 판정이 불가능해집니다.
섹션 순서·수익 카드 문구는 어드민 변경이므로 **서버 사이드 A/B가 가능**합니다(§6).

## 9. MVP 범위

**반드시 포함**
- 검색바 + 검색 화면 + `search_term` 수집 + 0건 로그
- 홈 7섹션 구조 + 섹션별 이벤트
- 수익 카드 3종 (동일 컴포넌트)
- 채팅 2탭 + 점/숫자 분리 + 빈 상태 CTA
- 어드민 컴포넌트 8종 관리 (§6)

**이번에 제외**
- 검색 자동완성·오타 교정·필터 — **검색어 로그가 수요를 알려준 뒤** 설계합니다
- 통합검색(모임 외 칼럼·상품)
- 공감 배지 (§4-4) — CX 검토 후 별도 릴리스
- 광고 인벤토리 실집행 — 안정화 4주 후
