홈여행만남모임 채팅마이

버리는 것이 아닙니다. IA(네비게이션 뼈대)만 바뀌고, v2.0에서 설계한 9섹션·수익 카드 3종·이벤트 16종·어드민 컴포넌트 8종·채팅 2탭은 그대로 4메뉴 안으로 상속됩니다. 개발자에게 "새로 만들 것이 없다"를 증명하는 것이 다음 섹션입니다.

    인연 진단 → 상담 예약 → 전화 상담. 시니어는 전화 전환이 강합니다. 상담 이탈 7.0%는 이미 잘 작동하는 페이지.

    시럽은 성인 등급 안내 병기

  4. 4

    단체미팅 — 일정·잔여석 중심

    가격 등급 확정 후 구독은 기본 참석권만 커버(§가격 재설계). 잔여 3석 이하 강조.

    이벤트 · meeting_apply_start / complete
