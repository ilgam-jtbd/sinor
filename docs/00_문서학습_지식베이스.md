## 1. 종합전략 v3 핵심

### 진단
- 회원 107,735명(시럽 49,862 · 시놀 57,873) · 운영 모임 1,561개 · 가입 CAC 2,836원
- 2025 매출 4.03억 · 매칭(시럽·시럽인연) 비중 66% · 시럽인연 단독 49%(1.97억)
- 월 매출 3,600만 vs 월 비용 4,160만 — **시럽인연 월 +2건이면 흑자권**
- 핵심 문장: "수익은 매칭이 내는데 앱의 주인공은 커뮤니티" / "배너는 광고로 읽히고, 카드는 추천으로 읽힙니다"

### GA4 실측 (2026.07.09~08.05, 28일)
- 웹 활성 사용자 5,750명 · 검색 유입 57% · 네이버가 구글의 2.2배(2,084 vs 966)
- AI 검색 유입 61명(챗GPT 47 · 제미나이 6 · 클로드 5 · 퍼플렉시티 3)
- 첫 방문자 93% · 봇/해외 트래픽 9.7%(싱가포르 293 · 우루무치 212)
- 이탈률: 단체미팅 12.0%(조회 1,480, 최고 의도) · 시럽인연 상담 7.0%(371) · 칼럼 38.1%(2,312) · 여행 72.7%(439)
- **7개월간 purchase 이벤트 20건 · 구매자 16명** — 무통장 입금이 측정에서 누락 추정

### 광고 실측 (네이버 검색광고, 7일)
- 광고비 75,922원 · 클릭 427 · 전환 0(전환추적 미설치)
- 예산 74%가 자동 확장검색, 시럽 데이팅에 54%, 매출 49%인 시럽인연에는 5.6%
- 등록 키워드 3,655개 중 클릭 발생 48개 · 96%가 최소입찰가 70원

### 전략 구조
- 입구: 시놀 커뮤니티(무료 모객) → 전환: 시럽인연(객단가 300~400만, 재결제율 47%) → 확장: 시니어 경제
- 확정: ① 시럽인연 올인 ② 시럽 유지 모드 ③ 시놀 단일 입구(단일 계정)
- 수익 3단계: T1(0~3개월, 있는 것 연결·월 흑자) / T2(3~9개월, 제휴 수수료화) / T3(9~18개월, 경제·데이터)
- 키워드: 88개 · 10~15개 묶음. "예산은 파는 키워드에, 콘텐츠는 모으는 키워드에"
- 채널: SEO(네이버 우선) · ASO(iOS 한국어 미등록·Play 데이터 안전 '암호화 안 됨' 재제출) · AEO(FAQ 구조화) · GEO(AI 크롤러 허용)
- 90일 과제: 광고 정리 · 전환추적+서치콘솔 · 카드 결제 전환+여행 동선 · 단체미팅 구독 출시
- KPI: 단체미팅 구독자 수 · 결제 완료율 · 시럽인연 월 건수 / ARPPU 9.2만 · 유료 CAC 1.67만 이내

## 2. 앱 홈·채팅 개편 기획서 v2.0

- 범위 A(홈 7섹션): 검색바 최상단 sticky(앱 내 검색 4,232명/28일인데 진입점 0) · 기획전 배너(radius 16px, 롤링 5초) · 카테고리 격자 2×5(한글 라벨 필수) · 수익 카드 3종(단체미팅·인연 진단·이번 주 여행) 분산 배치 · 신규 모임/지역 모임 가로 스크롤(20% 걸침) · 광고 슬롯(안정화 4주 후)
- 범위 B(채팅 2탭): '모임 / 1:1 대화'(오이 방식) · 탭은 점, 목록은 숫자 · 점 해제는 실제 열람 시점 · 빈 상태에 '모임 둘러보기' CTA
- 상위 지표: **재방문** (DAU/MAU 5.8% → 8%, 2024년엔 12~15%) · 월 신규 회원 5,964(2025.02) → 1,361(2026.07)
- 가드레일: 모임 참여 후 이탈률 · 첫 액션까지 시간 · CS '못 찾겠다' 문의
- **차단 조건: 측정 설정(search_term·섹션별 이벤트) 완료 전 배포 금지**
- Open Items 6건: 카테고리 수 / search_term 수집 여부 / 안읽음 카운트 제공 주체 / 1:1 대화 통합 범위 / 배너 운영 주체 / 지역 정보 보유율

## 3. 웹 개발 요구서 v1.0

- 목표: 웹 역할 재정의('회사 소개' → '앱 설치·전환 관문') · 설치 유도 도달률 1.4%(79/5,750) → 5%
- 구조 문제 3건: ① 여행이 외부 도메인(msinor.hanatour.com/dcr/) ② 단체미팅이 홈 앵커(#doz_menu_meeting, 색인·측정 불가) ③ /silove가 /silovematch의 접두어(지표 분리 불가)
- 요구 3군:
  - A군 앱 전환 동선: A1 스마트 배너 · A2 고정 설치 바(닫기 7일) · A3 칼럼 191편 하단 카드(주제별 분기) · A4 지연 딥링크 · A5 단일 스마트 링크 · A6 부모님께 보내기(자녀=공유, 설치 아님) · A7 설치 후 첫 화면
  - B군 페이지군별 단일 목표: 칼럼=설치 / 단체미팅=웹 완결 / 시럽인연 상담·여행=**앱 유도 금지** / 자녀=공유 / silove=시럽 앱(성인 등급 안내)
  - C군 측정: C1 크로스도메인·C2 결제 이벤트(**선행**) · C3 설치 기여 · C4 search_term · C5 봇 필터 · C6 서치콘솔 · C7 네이버 전환추적
- 충돌 10건: 하나투어 도메인 / 앵커 구조 / 경로 접두 / 상담 폼 직행(이탈 75.8% vs /blinddate 16.7%) / 앱 이원화 / 스토어 신호 / iOS 영어만 / 설치 기여 부재 / 무통장 기본값 / AI 크롤러 차단
- 의사결정 12건(Q1~Q12): 특히 **Q7(빌더 종류·코드 수정 범위)이 전체 실현 가능성을 좌우** · Q8 계정 통합 · Q9 하나투어 계약 · Q10 PG 빌링키 · Q11 AI 크롤러 · Q12 스토어 콘솔 보유 주체
- 가드레일: 시럽인연 상담 수 · 단체미팅 완료율 감소 시 실패 판정

- **핵심 가설: 패키지명·iOS ID로 보아 시럽이 원조 앱, 시놀(gathering)이 나중 분리 앱** — 2025 앱 이원화 기록과 일치, 계정·데이터 미연동의 구조적 원인 추정
