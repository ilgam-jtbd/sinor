## 0. 30초 요약

Cowork가 올린 **V3 4대 메뉴 IA**(홈/여행/만남/모임)를 받아 CC 세션에서 세 가지를 했습니다.

1. **V3가 v2.0을 버리지 않도록 매핑을 만들었습니다** — v2.0의 9섹션·수익 카드·이벤트·컴포넌트 규격이 4메뉴 안 어디로 가는지 1:1로 확정 (`docs/07`). 이게 없으면 "새 IA를 위해 기존 개발 자산을 다시 만드는" 최악이 됩니다
2. **4대 메뉴 목업 v3.0을 만들었습니다** — 홈·여행·만남·모임·마이페이지·채팅·웹 (HTML 아티팩트 + PPTX)
3. **개발 프롬프트를 CC용·Codex용으로 분리했습니다** — Cowork가 준 통합 프롬프트를 각 에이전트 강점에 맞게 나눴습니다

**결론 — V3 방향에 동의합니다.** 4대 메뉴가 v2.0 5탭보다 낫고, 기존 자산도 손실 없이 옮겨집니다.

## 1. V3 판단 — 동의하는 이유

Cowork의 4대 메뉴 판단이 맞습니다. 근거는 세 가지입니다.

1. **목적이 보입니다.** v2.0의 모임/라운지/+/채팅/마이는 "무엇을 하러 들어가는 앱인가"가 안 보입니다. 홈/여행/만남/모임은 시니어가 자기 목적을 바로 고릅니다
2. **수익 서비스가 메뉴 안으로 들어옵니다.** v2.0에서 시럽인연·단체미팅·트립은 메뉴 체계 밖 카드로만 존재했는데, V3에서는 만남·여행이 대메뉴가 됩니다. 여행은 시놀트립 멤버십이 이미 있어 독립 메뉴 승격 명분이 충분합니다
3. **기존 자산이 보존됩니다.** 콘텐츠 부족이 아니라 연결 부족이라는 진단이 맞습니다. 9섹션을 재배치하는 것이지 새로 만드는 게 아닙니다

## 2. 가장 중요한 산출물 — 9섹션 → 4메뉴 매핑

`docs/07_V3_IA_재정의.md`의 핵심 표입니다. **개발자에게 "새로 만들 것이 없다"를 증명합니다.**

| v2.0 홈 섹션 | V3 위치 | 상속 규격 |
|---|---|---|
| 검색바 | 홈 상단 | search_term 수집 |
| 기획전 배너 | 홈 | radius 16px·세션당 첫 노출 |
| 카테고리 격자 | **모임 상단** | 아이콘+한글 라벨 |
| 수익카드 단체미팅 | **홈+만남** | 잔여 3석 강조 |
| 새로 열린 모임 | 홈+모임 | 20% 노출·정원 표시 |
| 수익카드 인연진단 | **홈+만남** | 결과 전화 원탭 |
| 내 지역 모임 | 홈+모임 | 미설정 시 설정 유도 |
| 수익카드 이번주 여행 | **홈+여행** | 정가 vs 멤버십가 |
| 광고 슬롯 | 홈 (4주 후) | 동시 도입 금지 |

**빠지는 섹션 0개.** 대부분 홈(발견)과 전용 메뉴(목적 완수)에 이중 배치됩니다.

## 3. 채팅 — 탭만 빠지고 기능은 그대로

| 진입점 | 도달 |
|---|---|
| 모임 상세 → 모임 대화 | 모임 채팅방 |
| 상대 프로필/만남 → 1:1 대화 | 1:1 채팅방 |
| 헤더 메시지 아이콘 → 전체 대화 | 기존 모임/1:1 2탭 |

v2.0의 2탭·점/숫자·점 해제 규칙 그대로. **개발 관점에서는 라우팅 변경**이지 채팅 재개발이 아닙니다.

4대 메뉴별 4주 기여도를 측정해 하위 영역을 축소·재배치합니다.

## 8. 개발 착수 순서 (V3)

1. **Cowork가 4대 메뉴 IA 승인** (V3-1)
2. CC가 **Phase 0 조사** → `IMPLEMENTATION_PLAN.md` (코드 수정 없이 현재 구조 파악)
3. 계획 승인 후 **Phase 1** — 4탭 네비 + 마이페이지 이동 + 채팅 맥락 진입
4. Phase 2~4 — 홈 재배치 · 만남/여행 연결 · 웹
5. Phase 5 — 검증

**측정 설정(GA4·GTM·서치콘솔·전환추적)이 배포보다 먼저.** 이것이 유일한 차단 조건입니다.

## 8-B. 동작 프로토타입 (신규)

와이어프레임을 넘어 **실제 콘텐츠가 든 클릭 가능한 HTML 프로토타입**을 만들었습니다.

- `prototype/index.html` — 단일 파일, 외부 의존 없음. 상단 앱/웹 토글 · 하단 4대 메뉴 탭 · 카드 이동 · 마이페이지 오버레이가 실제로 동작
- 실측 데이터 — 회원 107,735명 · 모임 1,561개 · 시놀트립 49,900원/년 · 단체미팅 99,000원~ · 시럽인연 성혼비 없음
- 실제 화면 예시 — 강남 아침 산책·분당 바둑·파크골프 모임, 제주 한림 여행 멤버십가, 시럽/시럽인연/단체미팅 만남 분기
- 배포 — `docs/prompts/코워크_배포프롬프트_프로토타입.md` (GitHub Pages, 참조 예시와 동일 방식)
- 색·아이콘·카피는 디자인 단계 확정 초안. 구조·콘텐츠 배치 합의가 목적

**참조 사이트(banns0104.github.io)는 이 환경에서 접근 차단**이라 비주얼을 직접 보고 베끼진 못했습니다. 대신 시니어 접근성 기준(17px·48px·명도 대비 4.5:1)과 시놀 브랜드 톤(딥틸+감빛 코랄)으로 자체 제작했습니다.
