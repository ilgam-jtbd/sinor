## 0. 실행 환경 실측 (2026-08-08, Claude Code 원격 세션)

| 항목 | 실측 | 의미 |
|---|---|---|
| 본 리포 | 분석 전용 (실 개발 없음, 실서비스 코드 없음) | 모드 A는 실서비스 저장소 `add_repo` 확보 시에만 가능 |
| 외부 네트워크 | sinor.co.kr · play.google.com · apps.apple.com · crt.sh · hanatour.com 전부 차단 (프록시 403 / WebFetch EGRESS_BLOCKED) | 원격 세션 기본 정책은 default-deny — **모드 B 실행 전 네트워크 결정 필요** |

| PyPI/npm | 허용 (프록시 예외 목록) | androguard · dnspython 설치 가능 |

### 실행 경로 (선택 필요)

1. **원격 환경 네트워크 정책 완화 (권장)** — claude.ai/code 환경 설정에 허용 도메인 추가:
   `sinor.co.kr`, `*.hanatour.com`, `play.google.com`, `apps.apple.com`, `itunes.apple.com`, `crt.sh` (+ 조사 중 발견되는 CDN·API 호스트)
2. **로컬 Claude Code(데스크톱/CLI) 실행** — 네트워크 제약 없음, APK 추출 용이. 결과만 본 리포에 push
3. **오프라인 입력 기반** — HTML 저장본·APK/IPA·GA4 내보내기·어드민 캡처를 업로드 받아 현 세션에서 분석 (정밀도 하락 감수)

## 1. 실행 순서 — 입력이 확보되는 순서로 단계화

조기 보고 5조건(폐쇄형 빌더 / 계정 분리 / 빌링키 불가 / 콘솔 외주 단독 보유 / 하나투어 데이터 회수 불가)은 어느 단계에서든 발견 즉시 중간 보고.

### 1단계 — 입력 0, 외부 지문 (반나절)
- curl 원문 + **Playwright 렌더링 DOM 비교** → W1 빌더 확정 · W2 SSR/CSR · W7 태그(GTM은 지연 삽입되므로 렌더 후 DOM 필수) · W9 JSON-LD · W12 성인 게이트
- robots.txt · sitemap.xml · assetlinks.json · apple-app-site-association → Q11 · A4 · W4
- 서브도메인 열거: crt.sh JSON + `dnspython`(dig 대체)
- 스토어 리스팅 4종 WebFetch 조회 → 리스팅 표 검증 · Q12 1차 단서
- Playwright 성능 측정(LCP·워터폴) → W11
- 요청 간 1초 이상 · 총 200요청 이내 (프롬프트 절대 규칙 준수)

### 2단계 — APK/IPA 업로드 시 정적 분석 (1일)
- APK는 **사용자가 단말에서 추출해 업로드** (서드파티 미러는 변조 위험 — 실사 근거 부적합)
- `androguard`(aapt 대체): A1 개발 방식(libflutter/libhermes/index.android.bundle 지문) · A10 minSdk · 권한 · A5 푸시 · A6 분석 SDK
- `strings`로 API 호스트 추출 → S1
- **시놀·시럽 APK diff** → 1-2 핵심 가설("시럽이 원조 앱") 검증의 최강 수단
- IPA: unzip + python plistlib → Info.plist · Universal Links entitlement

### 3단계 — 실서비스 저장소 확보 시 코드 실사 (2~3일)
- GitHub이면 `add_repo`로 세션 추가 → 웹/앱/서버 서브에이전트 병렬 실사
- 여기서만 확정: S2~S6(프레임워크·DB·**계정 테이블 통합 S4**·**PG 빌링키 S5**·검색 구현) · A7 안읽음 카운트 · A9 홈 섹션 서버 응답 여부 · 특허 4건 구현 여부 · 어드민 8종 판정
- 환경변수는 키 이름만 수집 (값 금지)

### 4단계 — 권한·문서 기반 확인 (병행)
- GA4/GTM: 전용 MCP 없음 → 관리 화면 캡처 + 내보내기 CSV 업로드로 대체
- Q9(하나투어 계약) · Q10(PG 계약) · Q12(콘솔 보유 주체)는 기술 조사가 아닌 **문서·인터뷰 항목** — 1주차에 담당자 질의 발송, 회신을 신뢰도 표기해 보고서 통합

### 5단계 — 보고서 작성·커밋
- `docs/reports/시놀_기술스택_실사_YYYYMMDD.md` — 템플릿(`docs/templates/`) 준수
- 개발요구서 Q3~Q12 회신표와 1:1 매핑 → 요구서 v1.1 반영용

## 3. 도구 · 스킬 · MCP

### 그대로 쓰는 것
| 구분 | 항목 | 용도 |
|---|---|---|
| 기본 | Bash(curl·unzip·strings·python) · WebFetch/WebSearch | 외부 지문 · 스토어 리스팅 |
| 브라우저 | Playwright + Chromium (사전 설치) | SSR/CSR 판별 · 렌더 후 태그 검사 · 성능 · 캡처 |
| 서브에이전트 | Agent(Explore / general-purpose) | 저장소 확보 시 웹·앱·서버 병렬 실사 |
| MCP | github | 실서비스 리포 실사 · 산출물 PR |
| MCP | Google Drive · Gmail · Slack | GA4 내보내기·계약서·담당자 회신 수령 |
| MCP | Sentry | 모니터링 스택 확인 (시놀이 Sentry 사용 시 조직 연결) |
| MCP | Supabase · Vercel | 1단계 지문에서 해당 스택으로 판별될 경우에만 |

### 설치해서 쓰는 것 (PyPI 허용됨)
- `androguard` — aapt/apktool 대체 APK 분석
- `dnspython` — dig 대체 DNS 조회

### 만들 가치가 있는 것
- **`sinor-audit` 커스텀 스킬** — 절대 규칙 6조(읽기 전용 · 신뢰도 4단계 · 조기 보고 5조건)와 산출물 템플릿을 스킬로 고정 → 재실사 때마다 규칙 자동 적용
- (선택) MCP 레지스트리에서 Google Analytics / Play Console MCP 검색 가능 — 내보내기 파일로 충분하여 필수 아님

### 쓰지 않는 것
docx/pptx/xlsx(산출물 md) · security-review(변경 diff 대상) · PlayMCP·Descript·Adobe(무관)

## 4. 프롬프트 v2 보완 의견

1. **환경 의존 명령어** — `dig`·`aapt`는 환경에 없을 수 있음. "없으면 dnspython/androguard 대체" 명시 권장
2. **W7 태그 검사는 렌더링 기반으로** — GTM·GA4·네이버 스크립트는 JS 지연 삽입이 많아 `curl | head`만으로 오탐. Playwright 렌더 후 DOM 검사를 표준 절차화
3. **S4·S5·Q9는 외부 지문으로 확정 불가** — 조사 착수와 동시에 저장소 접근 요청·담당자 질의를 1주차에 병행 발송하도록 일정에 명시 ("미확인"으로 끝나는 보고서 방지)
