# 시놀 V3 IA 재정의 — 9섹션을 4대 메뉴로

작성 **시놀 김연재** · 2026-08-08 · 대외비
근거 V3 앱 홈 기획서·웹 요구서·목업(2026.08.09) + 정합기준 정본 2026-08
상태 **IA 방향 확정** · 개발 착수 전

> **이 문서가 하는 일** — V3의 4대 메뉴(홈/여행/만남/모임)가 "좋은 방향"이라는 판단은 끝났습니다.
> 남은 질문은 하나입니다: **v2.0에서 만든 9섹션·수익 카드·이벤트·컴포넌트 규격을 버리지 않고 4대 메뉴 안으로 어떻게 옮기는가.**
> 이걸 매핑으로 확정하지 않으면 "새 IA를 위해 기존 개발 자산을 다시 만드는" 최악이 됩니다.

## 0. 무엇이 바뀌고 무엇이 유지되는가

| | v2.0 (기능 중심) | V3 (목적 중심) | 판정 |
|---|---|---|---|
| **하단 네비** | 모임 · 라운지 · ＋ · 채팅 · 마이 (5탭) | **홈 · 여행 · 만남 · 모임 (4탭)** | **변경** |
| 개인 설정 | 하단 '마이' 탭 | **우측 상단 마이페이지** | 변경 |
| 채팅 | 하단 '채팅' 탭 | **맥락 진입** (모임 대화·1:1 대화·헤더 메시지) | 변경 |
| 홈 9섹션 | 검색바 + 9섹션 나열 | **9섹션을 4메뉴에 재배치** | **유지·재배치** |
| 수익 카드 3종 | 단체미팅·인연진단·이번주 여행 | 동일. 홈+만남+여행에 분산 | 유지 |
| 채팅 2탭·점/숫자 | 모임/1:1 대화 | 동일 (맥락 진입으로만 도달) | 유지 |
| 컴포넌트 8종 어드민 | 배포 없이 제어 | 동일 + 메뉴 순서 서버 제어 추가 | 유지·확장 |
| 이벤트 명세 | 16종 | 동일 + `primary_nav_tap`·`mypage_open`·`chat_entry` 신규 | 유지·확장 |
| 페이지군 단일 목표 | 유지 | 유지 | 유지 |

**한 줄** — IA(네비게이션 뼈대)만 바뀌고, 그 안에 담기는 콘텐츠·측정·운영 규격은 v2.0을 그대로 상속합니다.

## 1. 4대 메뉴 정의 — "내가 무엇을 하러 왔는가"

| 대메뉴 | 사용자 질문 | 담는 것 | 수익 연결 |
|---|---|---|---|
| **홈** | 오늘 뭐가 있지? | 오늘의 추천 · 빠른 메뉴 · 내 지역 모임 · 새 모임 · 칼럼 · 공지 | 단체미팅·인연진단·이번주 여행 카드 |
| **여행** | 어디 갈까? | 시놀트립 멤버십 · 일정 · 혜택 · 후기 | 연 49,900원 멤버십 |
| **만남** | 누구를 만날까? | 시럽 · 시럽인연 · 인연진단 · 단체미팅 | 시럽인연 상담 · 단체미팅 |
| **모임** | 무엇을 같이 할까? | 취미·운동·여행·문화·지역 소모임 · 모임 개설 | 커뮤니티 → 재방문·전환 |

**마이페이지(우측 상단)** — 프로필 · 관심사 · 지역 · 본인인증 · 내 모임 · 포인트 · 결제/구독 · 알림 · 고객센터 · 약관 · 로그아웃. 서비스 탐색과 개인 설정을 분리해, 여행/만남/모임을 보다가 설정 때문에 맥락을 잃지 않게 합니다.

## 2. 핵심 매핑 — v2.0 9섹션 → V3 4메뉴 ★

**이 표가 개발자에게 "새로 만들 것이 없다"를 증명합니다.** 왼쪽은 이미 설계·측정 규격이 있는 v2.0 자산이고, 오른쪽은 V3에서의 위치입니다.

| v2.0 홈 섹션 | V3 위치 | 상속하는 규격 | 비고 |
|---|---|---|---|
| ① 검색바 (sticky) | **홈 상단** | `view_search_results`·`search_no_result`·search_term 수집 | 플레이스홀더 「무엇을 찾으세요?」로 단순화 |
| ② 기획전 배너 | **홈** | radius 16px·롤링 5초·세션당 첫 노출 집계 | 어드민 제어 유지 |
| ③ 카테고리 격자 | **모임 상단** | 아이콘+한글 라벨·6개 이하면 가로 스크롤 | 모임 메뉴의 진입 격자로 이동 |
| ④ 수익카드 단체미팅 | **홈 + 만남** | `revenue_card_*`·잔여 3석 강조·동일 컴포넌트 | 홈=추천 노출, 만남=상세 |
| ⑤ 새로 열린 모임 | **홈 + 모임** | 가로 스크롤 20% 노출·정원 표시 | |
| ⑥ 수익카드 인연진단 | **홈 + 만남** | 결과 화면 전화 상담 원탭 | 만남의 시럽인연 최단 경로 |
| ⑦ 내 지역 모임 | **홈 + 모임** | 지역 미설정 시 설정 유도 카드 | |
| ⑧ 수익카드 이번주 여행 | **홈 + 여행** | 정가 vs 멤버십가·가격 실연동 | 여행 메뉴의 대표 상품 |
| ⑨ 광고 슬롯 | **홈** (안정화 4주 후) | 개편과 동시 도입 금지 | |

**빠지는 섹션은 없습니다.** 9개 모두 4메뉴에 자리가 있고, 대부분은 홈(추천 노출)과 전용 메뉴(상세)에 이중 배치됩니다. 이중 배치는 중복이 아니라 **홈=발견, 메뉴=목적 완수**의 역할 분리입니다.

## 3. 채팅 재배치 — 탭 제거, 데이터·2탭 유지

| 진입점 | 도달 화면 |
|---|---|
| 모임 상세 → '모임 대화' | 모임 채팅방 |
| 상대 프로필/만남 → '1:1 대화' | 1:1 채팅방 |
| 헤더 메시지 아이콘 → '전체 대화' | **기존 모임/1:1 대화 2탭** |

**유지되는 것** — v2.0의 채팅 2탭 구조, 점(탭)/숫자(목록) 규칙, 점 해제는 대화방 실제 열람 시점. 즉 **채팅 기능 자체는 그대로이고 진입 경로만 바뀝니다.** 개발 관점에서 기존 채팅 컴포넌트·API를 재사용하고 라우팅만 바꾸는 일입니다(개발 회신 D3 그대로 유효).

## 4. 신규 이벤트 — v2.0 16종에 3종 추가

| 이벤트명 | 파라미터 | 발생 |
|---|---|---|
| `primary_nav_tap` | `menu`(home/travel/meet/groups) | 하단 4대 메뉴 탭 |
| `mypage_open` | `entry_point` | 우측 상단 마이페이지 진입 |
| `chat_entry` | `source`(meeting/profile/header), `room_type` | 맥락형 채팅 진입 |

나머지 16종(`home_section_impression`·`revenue_card_*`·`meeting_apply_*`·`purchase` 등)은 v2.0 명세 그대로입니다. **4대 메뉴별 4주 기여도를 측정해 하위 영역을 축소·재배치**합니다.

## 5. 시럽 vs 시럽인연 — 만남 메뉴에서 차이를 명확히

V3가 새로 강조한 지점입니다. 만남 메뉴 안에서 목적을 갈라 보여줍니다.

| | 시럽 | 시럽인연 | 단체미팅 |
|---|---|---|---|
| 성격 | 친구·관심사 기반 가벼운 만남 | **진지한 인연**·전문 매니저 | 일정·지역 기반 자연스러운 만남 |
| 진입 문구 | "친구를 만나고 싶어요" | "진지한 인연을 찾고 싶어요" | "함께 만나요" |
| 최단 경로 | 시럽 앱 (성인 등급 안내) | **인연 진단 → 상담 예약 → 전화** | 일정·잔여석 → 신청 |
| 수익 | — | 객단가 300~400만 (성혼비 없음) | 참가비 99,000~300,000원 |

시럽 앱은 Play 18+이므로 만남 메뉴에서 시럽으로 보낼 때 **성인 등급 안내를 병기**합니다(정합기준 §6·기존 Q1 원칙 유지).
