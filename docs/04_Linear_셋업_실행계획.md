# Linear 셋업 실행 계획 — 팀 확정 즉시 적용

상태: **부분 진행** — 커뮤니케이션 스레드만 임시 생성. 프로젝트·초기 티켓은 팀 신설 후

**커뮤니케이션 스레드**: [WHO-224](https://linear.app/whocareskorea/issue/WHO-224/sinor싱크-cowork시놀-claude-code-전략기획-커뮤니케이션-스레드) — `[SINOR][싱크]` 접두로 구분. 팀 신설 시 이관합니다.

## 현황 (2026-08-08 확인)

Linear 워크스페이스에 팀이 **`Whocareskorea` 하나**뿐입니다. Linear MCP에는 팀 생성 도구가 없어 에이전트가 만들 수 없습니다.

## 결정 필요 — 운영체계 v1.0 §3-1

| 선택지 | 방식 | 장점 | 단점 |
|---|---|---|---|
| **A (권장)** | Linear에 `Sinor` 팀 신설 → `SIN-xx` 키 | 완전 분리. 지표 오염 없음 | 팀 생성은 사람이 직접 |
| B | 같은 팀에 시놀 프로젝트 + `SINOR:` 라벨 | 즉시 시작 | 이슈 키가 `WHO-xx`로 섞임 |
| C | Linear 미사용, 저장소 문서로만 교환 | 설정 불필요 | 상태 추적 불가 |

**에이전트가 한 것과 하지 않은 것**

- **한 것**: 커뮤니케이션 스레드 1건만 임시 생성(WHO-224). 세 세션을 잇는 채널이 없으면 이후 모든 협업이 막히고, 이 티켓 하나는 이관·삭제가 쉽습니다
- **하지 않은 것**: 초기 티켓 8건 생성. 실무 티켓이 `WHO-xx`로 쌓이면 후케어스 지표에 섞이고 되돌리기 어렵습니다. 팀 결정 후 일괄 생성합니다

## 팀이 생기면 바로 만들 것

**프로젝트**
```
이름: 시놀 앱·웹 전환 개편
요약: 앱 홈·채팅 개편 + 웹 앱설치 전환 동선. 종합전략 v3 S11·S15 실행.
      Cowork(전략·최종문서) ↔ CC(코드) ↔ 전략기획(진단·목업) 3자 싱크.
```

**라벨** `APP:HOME` `APP:CHAT` `WEB` `MEASURE` `DESIGN` `DECISION` `EXTERNAL`

**커뮤니케이션 스레드 티켓** (WHO-37 검증 패턴) — **WHO-224로 이미 생성됨.** 팀 신설 시 이관하고 키를 `SIN-1`로 바꿉니다.
