# 실무자 접속 승인 가이드 — Cowork / Claude Code 작업 전 준비

> **목적:** 실무자(PO·디자이너·개발)가 Cowork·Claude Code로 시놀 문서·프로토타입 작업을 시작할 수 있도록, **어떤 접근 권한을 누가 어떻게 주는지**를 한 장으로 정리합니다.
> **작성:** Claude Code · 2026-08-08

---

## 0. 한눈에 — 무엇이 필요한가

| 구분 | 대상 | 승인 주체 | 없으면 막히는 일 |
|---|---|---|---|
| A | **GitHub 저장소 접근** (`ilgam-jtbd/sinor`) | 저장소 소유자 | 문서·프로토타입 편집 자체 |
| B | **Claude 아티팩트 공유** | 아티팩트 소유자 | 배포 화면 열람 |
| C | **네트워크 egress 허용** | 환경 관리자 | 실사이트 크롤링·드라이브 다운로드 |
| D | **Cowork 커넥터/스킬 권한** | 각 실무자 | 문서 자동 생성·연동 |
| E | **운영 계정 권한** (GA4·GTM·서치콘솔·스토어 콘솔·PG) | 사내 담당 | 측정 부착 — **모든 개편의 선행 조건** |

**중요:** E가 없으면 화면을 바꿔도 좋아졌는지 나빠졌는지 판정할 수 없습니다. 웹 요구서가 "측정이 배포보다 먼저"라고 못 박은 이유입니다.

## 1. A. GitHub 저장소 접근

**필요 이유** — 기획 문서(`docs/`)와 프로토타입(`prototype/index.html`)이 모두 이 저장소에 있습니다.

**주는 방법 (소유자가 실행)**
1. https://github.com/ilgam-jtbd/sinor → **Settings → Collaborators**
2. **Add people** → 실무자 GitHub 계정 입력
3. 권한: 읽기만 필요하면 **Read**, 문서 수정까지면 **Write**

**Claude Code 세션에서 쓰려면**
- 세션에 저장소가 이미 붙어 있으면 그대로 사용
- 다른 저장소가 필요하면 담당자에게 요청 → 세션에서 `add_repo`로 추가
- 조직 정책으로 막히면: **Claude GitHub 설정**에서 관리자가 저장소를 허용해야 합니다 → https://claude.ai/admin-settings/claude-in-slack

## 2. B. Claude 아티팩트(디자인) 공유

**현재 상태** — 배포 화면 아티팩트는 **이미 공유 오픈됨**.
- 주소: https://claude.ai/code/artifact/bac52e13-ebb9-4e77-9d88-192e18cd731e

**추가 공유가 필요하면 (소유자)**
1. 아티팩트 페이지 우측 상단 **공유(Share)** 메뉴
2. 링크 공유 범위 선택 → 링크 전달
3. 본인 아티팩트 목록: https://claude.ai/code/artifacts

> 아티팩트는 **기본 비공개**입니다. 공유를 켜야 남이 열 수 있습니다.

## 3. C. 네트워크 egress 허용 — **현재 막혀 있음** 【확인됨】

Claude Code 세션의 아웃바운드는 조직 네트워크 정책이 통제합니다. **이번 세션에서 실제로 차단이 확인된 호스트**:

| 호스트 | 상태 | 막히는 작업 |
|---|---|---|
| `sinor.co.kr` | ❌ 403 차단 | 실사이트 크롤링·콘텐츠 대조·응답헤더 확인 |
| `drive.google.com` | ❌ 403 차단 | 드라이브 파일 다운로드 |
| `apkpure.com` | ❌ 403 차단 | APK 직접 수집 |
| `marrish.com` | ❌ 403 차단 | 일본 벤치마크 사이트 실사 |
| `github.com` 계열 | ✅ 허용 | 저장소·릴리스 (이 경로로 우회함) |

**푸는 방법** — 환경 생성 시 네트워크 정책을 선택합니다. 관리자가 더 넓은 정책의 환경을 만들고 그 환경에서 새 세션을 열면 위 호스트가 열립니다.
- 문서: https://code.claude.com/docs/en/claude-code-on-the-web

**임시 우회(이번에 실제 사용한 방법)** — GitHub만 열려 있으므로, 큰 파일은 **공개 저장소의 Release에 올리고 그 링크로 전달**했습니다. (예: `sinor-apk-temp`)

## 4. D. Cowork 커넥터·스킬 권한

Cowork에서 문서 작업을 시킬 때 필요한 권한입니다. **실무자 본인이 승인**합니다.

**커넥터 연결 (문서/드라이브/캘린더 등)**
1. Claude 설정 → **커넥터(Connectors)**
2. 필요한 것만 연결 — 예: Google Drive(문서 열람), GitHub
3. 연결 시 **범위(scope)를 확인** — 필요 이상 권한은 주지 않습니다

**스킬 사용**
- 문서 작성 자동화가 필요하면 해당 스킬을 활성화 (docx/pptx/xlsx 등)
- 조직 스킬은 관리자 승인이 필요할 수 있습니다

**작업 중 승인 팝업이 뜨면**
- 어떤 도구가 무엇을 하려는지 확인하고 승인/거부
- 파일 쓰기·외부 전송은 특히 확인 후 승인

> **원칙:** 최소 권한. 이번 작업에 필요한 것만, 끝나면 회수합니다.

## 5. E. 운영 계정 권한 — **가장 중요** 【선행 조건】

측정이 붙지 않으면 개편 성과를 판정할 수 없습니다. **공수는 거의 없고 계정 권한만 필요합니다.**

| 계정 | 필요 권한 | 용도 | 담당 |
|---|---|---|---|
| **GA4** | 편집자 | 이벤트 확인·전환 설정 | |
| **GTM** | 게시 권한 | 태그 삽입(코드 배포 불필요) | |
| **구글 서치콘솔** | 소유자/전체 | 색인·검색어 | |
| **네이버 서치어드바이저** | 관리 | 색인 | |
| **네이버 검색광고** | 관리 | **전환추적 3지점**(상담·신청·결제) — 현재 미설치, 7일 427클릭 전환 0 | |
| **웹 플랫폼(아임웹 추정)** | `<head>` 코드 삽입 | 스마트 배너·GTM·스키마 | |
| **Play Console / App Store Connect** | 앱 관리 | 스토어 제목·데이터안전·스크린샷 | |
| **PG(TossPayments)** | 관리 | 빌링키(정기결제) 가능 여부 | |
| **Firebase** (`sinor-8b864`) | 편집자 | 푸시·Crashlytics·RemoteConfig | |
| **Agora / Easemob** | 관리 | 화상·채팅 SDK 키 확인 | |

> Firebase 프로젝트·SDK 구성은 APK 역컴파일로 확인했습니다 → `docs/reports/시놀_시럽_개발스택_역컴파일_20260808.md`

## 6. 승인 요청 문구 (복사해서 사용)

```
[시놀 개편 작업 접근 권한 요청]

작업: 시놀 앱·웹 4대 메뉴 개편 — 문서 정합 및 측정 부착
기간: (기입)
요청자: (기입)

1) GitHub  ilgam-jtbd/sinor  — Read 또는 Write
2) 운영 계정 (측정 선행)
   - GA4 편집자 / GTM 게시 / 서치콘솔 소유자
   - 네이버 서치어드바이저·검색광고 전환추적
   - 웹 플랫폼 head 코드 삽입 권한
   - Play Console·App Store Connect
3) (선택) 네트워크 정책 완화 — sinor.co.kr 크롤링이 필요한 경우

사유: 측정이 부착되지 않으면 개편 전후 비교가 불가능합니다.
GTM·서치콘솔은 개발 공수가 없고 계정 권한만 있으면 당주 처리 가능합니다.
```

## 7. 보안 원칙 (전원 준수)

1. **프로덕션 변경 금지** — 조사는 읽기 전용. 배포·마이그레이션·설정 변경·계정 생성 금지
2. **개인정보 접근 금지** — 회원 데이터 조회·다운로드 금지. 스키마 구조만 확인
3. **부하 금지** — 크롤링은 요청 간 1초 이상, 총 200요청 이내
4. **키 취급** — 서버 secret key는 절대 클라이언트·문서·저장소에 두지 않습니다. 클라이언트 공개키(Firebase API key 등)는 앱에 내장돼 비밀이 아니지만, 그래도 문서에 나열은 최소화
5. **대외비 원본**(pptx·docx·pdf)은 저장소에 커밋하지 않습니다 — 요약본만
6. **막히면 우회하지 말고 보고** — 임의 대안을 실행하지 않습니다
