# ■ 붙여넣을 프롬프트 (여기부터 끝까지)

시놀 **운영 백오피스** 문서를 사내 배포본으로 정리해 주십시오. Claude Code가 만든 설계서와 화면 목업이 있고, 이를 **워드 문서(내부용)**로 옮기는 작업입니다. 새 기획을 하지 말고 첨부 내용을 정리·보강하십시오.

## 1. 배경 — 왜 지금 만드는가

콘텐츠와 이벤트를 다양하게 운영하려면 **개발 배포 없이 바꿀 수 있는 범위**가 곧 실험 속도입니다. 지금은 운영 변경마다 개발이 필요해 개선 주기가 스프린트 단위로 늘어납니다.

**기존 관리자 화면 추적 결과 (확정)** — 자사 앱 APK 역컴파일에서 **시놀 전용 관리자 화면은 없습니다.** 검출된 admin 문자열은 전부 SDK 소속(Easemob 그룹 방장·AppLovin MAX·MySQL 드라이버)입니다. 웹은 아임웹 페이지 편집형이라 홈 섹션 순서·수익 카드 노출·이벤트 예산 같은 **동적 제어가 불가**합니다. 따라서 **기존 화면 업데이트가 아니라 신설**입니다. 이 판단을 문서 서두에 명시해 주십시오.

## 2. 문서에 반드시 담을 것

1. **IA 12메뉴** — 대시보드 / 콘텐츠 / 이벤트 / 상품·구매 관리 / 커뮤니티·매칭 / 회원 관리 / 알림 관리 / 자동화 / **QA·개선 요청** / **그로스·A/B** / 측정 연결 / 설정·권한
2. **어드민 관리 대상 8종** (개발 요구서 §4) — 각 항목의 운영자 조작·제약·필수 이벤트
3. **이벤트 관리** — 친구초대 5,000원 · 모임개설 11만P. 예산 한도·어뷰징 방지·성과 지표
4. **상품·구매 관리 · 커뮤니티·매칭** — **기존 확정분 승계**입니다. 단체미팅 일정/등급, 시럽인연(성혼비 0 고정), 시놀트립(연 49,900), 매칭·배정 규칙을 **다시 설계하지 말고** 기존 확정 내용을 옮겨 적으십시오
5. **QA·개선 요청 (한 메뉴 · 두 탭)** — [탭1] QA(버그) / [탭2] 개선 요청. 접수 시 화면경로·앱버전·기기·오류·스크린샷 자동 수집. **개발 이관 전에 에이전트가 먼저 답합니다**(분류 A 이미 가능 / B 설정으로 가능 / C 문서에 답 있음 / D 개발 필요 / E 판단 필요). MCP 연동 — GitHub(이슈·릴리즈 노트·**릴리즈 발행**) · Linear(티켓) · Sentry(오류 자동 연결) · Slack(통지). **릴리즈 발행은 관리자 승인 후에만** 가능하다는 점을 반드시 명시
6. **그로스·A/B·CRO** — 도구는 **새로 사지 않습니다.** Firebase Remote Config(앱 탑재 확정)·GA4·GTM·Looker Studio 무료 조합, PostHog·Sentry는 무료 구간(요금 재확인 대상). Google Optimize(2023년 종료)와 유료 CRO SaaS는 사용하지 않음. **저빈도 전환(결제·상담)은 현 트래픽에서 A/B 판정 불가**이므로 대체 판정(전후 비교+세그먼트 대조+정성 관찰)을 함께 적을 것
7. **운영 가드레일 8종** — 미리보기 필수 · 가격 DB 연동 · 수익카드 3종 연속 배치 금지 · 앱 유도 금지 구역 · 웹뷰 맥락 자동 분기 · 변경 이력 · **가드레일 지표 없는 실험 등록 반려(중간 피킹 금지)** · **릴리즈 발행 관리자 승인**
8. **권한(RBAC) 6역할** — 콘텐츠·이벤트·상품·매니저·**그로스 담당**·관리자
9. **측정 연동** — 항목 생성 시 이벤트 자동 부착. `purchase`는 TossPayments·Play Billing 두 경로 모두

## 3. 표기 규칙

- 수치는 **정합기준 정본(`docs/03`)이 유일 출처**. 새 숫자를 만들지 마십시오
- 확인란 주체는 **「신진영 COO · 김민지 대표 확인」**으로 통일
- 신뢰도는 확정 / 유력 / 추정 / 미확인 4단계
- 문서에 이슈·충돌을 서술하지 말고, 결정이 필요한 항목은 **색상 확인란**으로만 표현

## 4. 결정이 필요한 항목 (확인란으로)

| 항목 | 선택지 |
|---|---|
| 구축 방식 | ☐ 아임웹 확장 ☐ 별도 백오피스 신규 구축 |
| 이벤트 예산 한도 | 친구초대 월 ______ / 모임개설 월 ______ |
| 어뷰징 방지 정책 | ☐ 1인 지급 상한 ☐ 중복 계정 차단 ☐ 개설 후 최소 활동 조건 |
| 단체미팅 가격 등급 | 99,000~300,000원 중 구독 커버 등급 |
| 회원 계정 통합 | ☐ 웹·앱 동일 user ☐ 분리 (자동 초대·설치 기여의 전제) |
| 이슈 트래커 | ☐ GitHub Issues 단독 ☐ Linear 병행 (둘 다 MCP 연결됨 — 요금·편의로 택일) |
| 분석 도구 요금 | PostHog·Sentry 무료 티어 한도 초과 시 예산 ______ / 월 |
| QA 접수 창구 | ☐ 백오피스 단일 ☐ 슬랙 병행 |

## 5. 하지 말 것

- 개인정보(회원 상세) 조회 기능을 설계에 넣지 마십시오. 이 도구는 **집계만** 봅니다
- 이벤트 예산·어뷰징 정책 수치를 임의로 확정하지 마십시오 — 경영 결정 대상입니다
- 성혼비 0은 시스템 고정값입니다. 운영자 변경 가능 항목으로 적지 마십시오
- 상품 구조·매칭 규칙을 **새로 설계하지 마십시오.** 기존 확정분을 옮겨 적는 자리입니다
- 분석 도구 요금을 「영구 무료」로 단정하지 마십시오. 무료 **구간**이 있다는 뜻이며 계약 시점 재확인 대상입니다
- 릴리즈 발행을 에이전트 자동 실행(L1)으로 적지 마십시오. 반드시 관리자 승인 단계가 있습니다
