# ■ 트랙 2 — 백오피스 초안 정리 (여기부터)

시놀 **운영 백오피스** 설계를 **초안 문서**로 정리해 주십시오. 첨부한 설계서와 화면 목업을 워드로 옮기는 작업이며, **새 기획을 하지 마십시오.**

## 1. 이 문서는 초안입니다 — 표지에 명시

**「초안 — 구조 합의용. 구축 방식 결정 전까지 개발 착수 문서가 아님」**을 표지와 머리말에 적어 주십시오. 확정본처럼 읽히면 개발이 먼저 시작됩니다.

## 2. 배경 — 왜 지금 만드는가

콘텐츠와 이벤트를 다양하게 운영하려면 **개발 배포 없이 바꿀 수 있는 범위**가 곧 실험 속도입니다. 지금은 운영 변경마다 개발이 필요해 개선 주기가 스프린트 단위로 늘어납니다.

**기존 관리자 화면 추적 결과 (2026-08-09 정정) 【확정】** — **어드민은 이미 존재합니다.** 시놀 어드민 · 시럽인연 어드민 2종이 운영·개발 중입니다(대시보드 — 월별 매출·매칭 현황·매니저별 현황·인구통계 / 매니저 관리 / 준회원 관리). APK에 **앱 내** 관리자 화면이 없었던 것은 사실이나(어드민은 별도 웹), 이를 근거로 「어드민 부재」로 본 초판 판단은 오류였습니다.

웹(아임웹)은 페이지 편집형이라 홈 섹션 순서·수익 카드 노출·이벤트 예산 같은 **동적 제어는 여전히 불가**합니다. 따라서 이 문서는 **「신설」이 아니라 「기존 어드민 2종 + 운영 레이어 확장」**입니다. 서두에 그대로 명시하고, **기존 어드민 화면 목록 확보가 신규 범위 확정의 선행 과제**임을 함께 적어 주십시오.

> **아임웹 종료 임박** — 슬랙 보고 기준 2026-08-10 추정입니다. 사실이면 「아임웹 확장」 선택지가 사라지므로, 구축 방식 확인란에 **종료일 확인 결과에 따라 자동으로 「신규 구축」으로 확정됨**을 각주로 달아 주십시오.

## 3. 담을 것 — 12메뉴

```
① 대시보드   ② 콘텐츠   ③ 이벤트   ④ 상품·구매 관리*   ⑤ 커뮤니티·매칭*
⑥ 회원 관리  ⑦ 알림 관리  ⑧ 자동화  ⑨ QA·개선 요청   ⑩ 그로스·A/B
⑪ 측정 연결  ⑫ 설정·권한
```
`*` **④·⑤는 기존 확정분 승계입니다.** 상품 구조·가격 정책·매칭 규칙을 **다시 설계하지 말고** 기존 확정 내용을 옮겨 적으십시오.

**장별로 반드시 들어갈 것**

1. **어드민 관리 대상 8종**(개발 요구서 §4) — 항목별 운영자 조작·제약·필수 이벤트
2. **이벤트 관리** — 친구초대 5,000원 · 모임개설 11만P. 예산 한도·어뷰징 방지·성과 지표
3. **회원 관리** — 이름·연락처 **기본 마스킹**, 해제 시 사유 입력+로그. 목록에 개인 식별 열 없음, **CSV·엑셀 내보내기 기능 없음**
4. **알림 관리** — 푸시·인앱·알림톡. 가드레일: 빈도 상한 · **21:00~09:00 발송 차단** · 수신거부 존중 · 세그먼트에 개인정보 미사용
5. **QA·개선 요청 (한 메뉴 · 두 탭)** — [탭1] QA(버그) / [탭2] 개선 요청. 접수 시 화면경로·앱버전·기기·오류·스크린샷 자동 수집, **운영자에게 재현 절차를 쓰게 하지 않음.** 개발 이관 전 **에이전트가 먼저 답함**(A 이미 가능 / B 설정으로 가능 / C 문서에 답 있음 / D 개발 필요 / E 판단 필요)
6. **그로스·A/B·CRO** — 신규 SDK 없이 **Firebase Remote Config**(앱 탑재 확정)·GA4·GTM·Looker Studio 조합. **저빈도 전환(결제·상담)은 현 트래픽에서 A/B 판정 불가**임을 명시하고 대체 판정(전후 비교+미노출 세그먼트 대조+정성 관찰 5명) 병기
7. **자동화 레벨** — L1 자동 / L2 초안→승인 / L3 탐지→알림. **절대 자동화하지 않는 것** — 제재·환불·개인정보 열람·예산 집행·가격 변경
8. **운영 가드레일 8종** — 미리보기 필수 · 가격 DB 연동 · 수익카드 3종 연속 배치 금지 · 앱 유도 금지 구역 · 웹뷰 맥락 자동 분기 · 변경 이력 · **가드레일 지표 없는 실험 등록 반려(중간 피킹 금지)** · **릴리즈 발행 관리자 승인**
9. **권한(RBAC) 6역할** — 콘텐츠 · 이벤트 · 상품 · 매니저 · 그로스 담당 · 관리자
10. **측정 연동** — 항목 생성 시 이벤트 자동 부착. `purchase`는 TossPayments·Play Billing **두 경로 모두**
