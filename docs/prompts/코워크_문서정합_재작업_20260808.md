## 1. 확정 사항 8가지 — 네 문서 모두 이것과 일치해야 합니다

1. **성공지표 1순위 = 매출 전환.** 앱 설치 유도 도달률은 **2순위**로 강등. (기존 웹 요구서는 앱 설치가 1순위였음 → 교체)
   - 단, **착수 1순위는 여전히 "측정 부착"**입니다. 결제 완료가 7개월 20건만 잡히는 상태에서는 매출을 판정할 수 없습니다.
2. **웹 홈 히어로 = 매출 CTA** (무료 인연 상담 · 단체미팅 신청). 히어로에 앱 설치 버튼을 넣지 않습니다.
3. **페이지별 단일 목표를 화면에 "목표 배지"로 명시.** 만남·여행 = 매출(앱 유도 없음) / 모임·칼럼 = 앱 설치 / 자녀 타깃 = 공유.
4. **만남 = 1:1(시럽)·단체미팅·시럽인연** 3분기 + **공감 배지**(마리슈 「리본 마크」 벤치마크: 재혼 이해·자녀 이해·사별 공감 — **본인이 스스로 다는 신호**, 시스템이 붙이는 낙인이 아님).
5. **칼럼 명칭 유지.** 후기(우리들의 이야기)는 별도 메뉴로 만들지 않고 **만남 블록 직후 사회적 증거**로 배치. 칼럼은 시니어칼럼 191편(검색 엔진 + 글 하단 전환 카드).
6. **앱 다운로드 = 2순위 CTA.** 상담·결제 흐름은 건드리지 않되 항상 닿게 — **① 헤더 우측 「앱 설치」 칩(상시)** + **② 스크롤 시 하단 고정 다운로드 바**(웹 요구서 §6.1, 닫기 가능).
7. **웹은 두 가지 맥락으로 존재** 【역컴파일로 확정】 — 앱이 **`web.sinor.co.kr`를 웹뷰로 임베드**합니다.
   - **웹 단독**: 주소창 · 설치 칩 · 고정 다운로드 바 노출
   - **앱 내 웹뷰**: 앱 헤더(‹ 시놀 ✕)로 바뀌고 **설치 유도 전부 숨김** — 이미 앱 안인 사용자에게 설치를 권하지 않습니다. 목표는 상담·신청·결제 완결
7-2. **앱 하단탭 = 4개 확정** (홈·여행·만남·모임). **칼럼 탭은 신설하지 않고** 칼럼 글을 홈 「칼럼·정보」 섹션과 주제별 맥락 메뉴에 배치합니다. 【대표 확정】
8. **이벤트 2종 상시 노출** (매출·앱설치 동시 레버) — 히어로 매출 CTA **바로 아래** 2분할 배치. 기간 한정이 아니라 **상시** 【대표 확정】
   - **친구초대 5,000원 서로 받기** → `sinor.co.kr/?utm_source=app&utm_medium=invite&utm_campaign=inviteFriendsByLink`
   - **모임개설 11만 포인트** → 모임 섹션에도 강조 배너로 이중 배치
   - 문구는 맥락별로: 웹 단독 「앱 받고 초대하기 / 앱에서 개설하기」 · 앱 내 웹뷰 「친구 초대하기 / 모임 개설하기」
