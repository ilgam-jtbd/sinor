## 1. 이번 회차에 확정된 5가지 (모든 문서에 공통 반영)

이번 반복에서 대표님이 확정했거나 프로토타입에 반영된 변경입니다. **네 문서 모두 이 5가지와 일치해야 합니다.**

1. **성공지표 1순위 = 매출 전환.** 앱 설치 유도 도달률은 **2순위**로 내린다. (기존 웹 요구서는 앱 설치 도달률이 1순위였음 → 교체)
2. **웹 홈 히어로 = 매출 CTA** (무료 인연 상담 · 단체미팅 신청). 히어로에 앱 설치 버튼을 넣지 않는다. 앱 유도는 **모임·칼럼 구역에서만**.
3. **페이지별 단일 목표**를 화면에 "목표 배지"로 명시한다: 만남·여행=매출(앱 유도 없음) / 모임·칼럼=앱 설치 / 자녀 타깃=공유.
4. **만남 = 1:1(시럽)·단체미팅·시럽인연(결혼·재혼)** 3분기 + **공감 배지**(일본 마리슈 「리본 마크」 벤치마크: 재혼 이해·자녀 이해·사별 공감 — 본인이 스스로 다는 신호).
5. **칼럼 명칭 유지.** 후기(우리들의 이야기)는 별도 메뉴로 만들지 않고 **만남 블록 직후 사회적 증거**로 배치(성혼·매칭 후기 → 상담 전환에 기여). 칼럼 섹션은 시니어칼럼 191편(검색 엔진, 글 하단 전환 카드).
6. **앱 다운로드 = 성공지표 2순위 CTA.** 상담·결제 인라인은 건드리지 않되, 앱 다운로드를 항상 닿게 한다 — **① 상단 헤더 우측 '앱 설치' 칩(상시)** + **② 스크롤 시 폰 하단 고정 다운로드 바**(웹 요구서 §6.1 하단 고정 설치 바, 닫기 가능). 만남 상담·여행 결제 흐름에는 인라인 앱 유도를 넣지 않는다.

## 2. 문서별 갱신 체크리스트

### ① 앱 화면 기획서 (docx) — "목적형 4대 메뉴 홈·여행·만남·모임"

- [ ] **만남 섹션**: 1:1(시럽·18+ 병기)/단체미팅/시럽인연 3분기 구조를 명시하고 **공감 배지** 컴포넌트를 추가한다.
- [ ] **여행 섹션**: "시놀트립 구독 + 이벤트 여행" 두 축으로 정리(구독 멤버십 연 49,900원 · 정가 vs 멤버십가).
- [ ] **AS-IS 정확화**: 실제 앱 현재 하단은 5탭(홈·내 모임·**스토리**·대화방·내정보). 이를 목적형 4탭(홈·여행·만남·모임)으로 재편 — 스토리(글)는 모임/칼럼으로, 대화방은 맥락 진입, 내정보는 우측 상단 마이페이지로 흡수.
- [ ] 성공지표 표가 있으면 **1순위=매출**로 정렬.
- [ ] iOS 앱 ID는 **미확인(귀속 충돌)**으로 표기 — 확정으로 쓰지 않는다(`6474283649`↔`6503413274`).

### ② 웹 개발 요구서 (docx) — "같은 4대 메뉴, 검색 유입을 전환으로"

- [ ] **§7 성공지표**: 1순위를 **매출 전환(결제 완료 이벤트)**으로 교체, 앱 설치 유도 도달률(1.4%→5%)은 2순위로. 가드레일은 유지.
- [ ] **§3 홈 개편**: 히어로 CTA를 **앱 설치 → 매출(상담·신청)**로 교체.
- [ ] **§5 페이지별 단일 목표**: 그대로 유지하되, 화면에 "목표 배지"로 시각화됨을 반영. 만남·여행=앱 유도 없음 재확인.
- [ ] **메뉴**: 홈·여행·만남·모임·**칼럼**(스토리로 개명하지 않음). 후기는 만남 블록에 사회적 증거로 배치.
- [ ] 만남에 **공감 배지**(마리슈) 추가. 시럽 유도는 /silove 내부 + 18+ 병기.
- [ ] **§6.1 앱 설치 동선**: 상단 헤더 '앱 설치' 칩 + 스크롤 하단 고정 바를 성공지표 2순위 CTA로 명시(상담·결제 흐름 침범 금지).
- [ ] iOS 앱 ID 미확인 표기.

### ③ 개발자 작업 프롬프트 (md) — CC + Codex

- [ ] **만남 목적 선택(3-3)**에 공감 배지 컴포넌트 티켓 추가(프로필·참가자 목록·인연 진단 결과에 노출, 선택형·불이익 없음).
- [ ] **측정 우선순위**: 매출 1순위에 맞춰 `purchase`·상담/신청 완료 이벤트를 최상단으로. 설치 기여는 그다음.
- [ ] **웹 히어로/성공지표**를 매출 우선으로 반영(5-2 SEO 섹션의 우선순위와 정합).
- [ ] **충돌 해소 필요** — 현재 md 규칙에 "APK/IPA 역공학 금지"(공개 스토어·웹 콘텐츠만)가 있는데, 별도 트랙에서 **자사 앱(시놀·시럽) APK 역컴파일 기술 실사**가 진행 중. → 문구를 "실서비스 그로스 작업은 공개 콘텐츠만 사용 / 자사 APK 역컴파일은 **기술 실사 트랙에서 자사 자산에 한해 허용**"으로 구분해 정리. (대표 확인 권장)
- [ ] AS-IS 5탭(홈·내모임·스토리·대화방·내정보) 정확 반영.

### ④ 화면 목업 (pptx)

- [ ] **웹 목업 슬라이드 추가/갱신**: 매출 우선 웹 IA(히어로 매출 CTA → 만남 → 후기 → 여행 → 모임=앱설치 → 칼럼 → 부모님 공유 → 앱 다운로드)를 현재 프로토타입 기준으로.
- [ ] **만남 슬라이드**: 공감 배지 추가, 3분기 구조.
- [ ] "색·카피는 디자인 단계에서 정합" → **이제 프로토타입에서 확정됨**으로 갱신(배포 URL 참조).
- [ ] 성공지표 슬라이드가 있으면 1순위 매출로.

## 3. 정합 규칙 (전 문서 공통 — 어기면 반려)

1. **수치는 정합기준 정본(`docs/03`)이 유일 출처.** 문서 간 숫자가 다르면 정본에 맞춘다.
2. **앱 유도 = 시놀 앱 단일.** 시럽 앱 유도는 `/silove` 내부에서만 + 성인(18+) 등급 병기. 시럽인연 상담·여행 결제 페이지에는 앱 유도 금지.
3. **수익 카드**는 콘텐츠 카드와 동일 컴포넌트(테두리·배경·「광고」 표기 금지), 3종 연속 배치 금지.
4. **접근성**: 본문 17px · 터치 48px · 대비 4.5:1.
5. **미확인 항목**은 비우지 말고 "미확인 — 확인 방법"을 적는다(예: iOS 앱 ID).
