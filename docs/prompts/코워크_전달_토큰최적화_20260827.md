## 1. 왜 이 문서인가

개발팀에서 **"토큰이 너무 빨리 닳는다"**는 문제 제기가 있었습니다. 원인을 좁혀 보면 도구 문제가 아니라 **컨텍스트 운영 문제**입니다. 그런데 이건 비용만의 문제가 아닙니다 — 컨텍스트가 차면 규칙을 잊고, 아까 정한 걸 다시 묻고, 실수가 늘어납니다. 이미 이 저장소 작업에서도 관찰됩니다.

그래서 "아껴 쓰자"는 당부가 아니라 **진단 → 처방 → 측정** 순서를 가진 실행 문서로 만들었습니다.

### 근거 (전부 출처 명시)

### 이 저장소에 맞춘 부분

일반론만 넣지 않았습니다. §1 하단에 **시놀 작업에서 실제로 관찰된 4가지**를 넣었습니다.

- **정본 문서 재독** — 학습정리·정합기준 정본 같은 20KB급 md를 매 세션 통째로 읽는 문제
- **핸드오프 왕복** — CC ↔ Cowork 문서가 필요하지만 쓰는 쪽·읽는 쪽 모두 토큰을 씀
- **대용량 fetch** — 스토어 페이지를 통째로 받으면 네비·푸터·국가목록까지 전부 들어옴
- **빌드 로그** — pptx·docx 빌드, LibreOffice 변환, 렌더 QA 출력의 반복 누적

§6에는 이 저장소에 바로 적용할 6단계를 뒀습니다 — CLAUDE.md 감사 → 규칙 분리 → AGENTS.md 신설 → 조사 위임 에이전트 → 훅·세션 정리 → 점검 주기.

## 3. CC가 할 일

### 3-1. 배포

```
1. 첨부 HTML을 devops/index.html 로 배치 (또는 저장소 관례에 맞는 경로)
2. gh-pages 반영 → https://ilgam-jtbd.github.io/sinor/devops/
3. 링크 회신
```

**확인 사항 3개**

- 콘솔 오류 0 (코워크 검증 완료 — Playwright 콘솔 에러 0건)
- 가로 스크롤 없음 (모바일 640px 기준 반응형 처리됨)
- `noindex` 유지 (내부 문서)

### 3-2. 복사 버튼 동작 확인

이 페이지는 **개발자 대상**이라 터미널 블록마다 복사 버튼을 넣었습니다(`navigator.clipboard`). GitHub Pages는 HTTPS라 정상 동작하지만, 배포 후 한 번 눌러 확인해 주십시오. 실패 시 버튼에 "복사 실패"가 표시되고 페이지는 그대로 동작합니다.

### 3-3. 이어서 제안 (별건, 판단 필요)

문서 §6이 이 저장소에 적용할 6단계인데, **1~3번은 CC가 바로 착수할 수 있습니다.**

| 단계 | 작업 | 비고 |
|---|---|---|
| 1 | 루트 `CLAUDE.md` 줄 수 감사 → 200줄 초과 시 분류 | 문서 §4 프롬프트 사용 |
| 2 | `.claude/rules/` · 하위 폴더 `CLAUDE.md`로 분리 | 조건부 로딩 |
| 3 | `AGENTS.md` 신설 (Codex용) | 골격은 문서 §5에 있음 |

**단, 자동 병합은 하지 마십시오.** 변경안을 PR로만 올리고 병합은 사람이 합니다 — 시놀 팀 운영 원칙(자동 편집 차단은 권한·설정으로 제어).

## 4. 지킬 것

- **수치를 만들지 않습니다.** 공식 문서에 없는 세부(autocompact 파라미터·스킬 토큰 상한 등)는 "공식 미기재"로 표기하고 지어내지 않습니다.
- **VELOR 수치 미포함.** §7 측정 표는 비워 뒀습니다. 실측이 생기면 그때 채웁니다.
- **API 키·비밀번호·회원 데이터 미기재.** 문서 전체에 없습니다.
- **프로덕션 변경 금지.** 이 문서는 읽기 자료이며 배포 외 다른 변경을 유발하지 않습니다.
- **`/learn/`과 톤 구분.** 학습 자료(딥틸·코랄)와 달리 이 문서는 개발자용(슬레이트·앰버 + 터미널 블록)으로 의도적으로 구분했습니다. 통일하지 마십시오 — 대상이 다릅니다.
