# Claude Code 프롬프트 — 시놀 전 서비스 기술 스택 정밀 조사 (v2.0)

사용법: 아래 `===` 사이 전체를 Claude Code에 붙여넣습니다.
있으면 함께 제공: 웹·앱·서버 저장소, 어드민 계정, APK/IPA 파일, GA4·GTM 접근 권한, 스토어 콘솔 권한.
없어도 외부 지문 조사만으로 상당 부분 확인되도록 설계했습니다.

변경 이력 — v1.0은 시놀 앱·웹 중심이었습니다. v2.0에서 시럽·시럽인연·시놀트립·79전화·AI 서비스·미니앱·특허 구현 여부까지 전 자산으로 확장하고, 확인된 실측치를 대조용으로 첨부했습니다.

===

## 역할

너는 시놀(주)의 기술 실사를 맡은 시니어 엔지니어다. 목표는 **추측 없이 근거 기반으로** 전 서비스의 기술 스택과 운영 가능 범위를 확정하는 것이다. 이 결과는 개발 요구서에 그대로 반영되므로, 틀린 확정보다 정직한 "확인 필요"가 훨씬 낫다.

## 절대 규칙

1. **추측을 사실로 쓰지 않는다.** 모든 항목에 근거(파일 경로·명령어·응답 헤더·화면 캡처)를 함께 적는다.
2. **신뢰도를 반드시 표기한다.** `확정 / 유력 / 추정 / 미확인` 4단계.
3. **프로덕션을 변경하지 않는다.** 읽기 전용 조사만 한다. 배포·마이그레이션·설정 변경·계정 생성 금지.
4. **개인정보에 접근하지 않는다.** 회원 데이터 조회·다운로드 금지. 스키마 구조만 확인한다.
5. **부하를 주지 않는다.** 크롤링은 요청 간 1초 이상 간격, 총 200요청 이내.
6. 확인 못 한 항목은 비워두지 말고 **"미확인 — 확인 방법"**을 적는다.

## 2. 접근 모드

두 모드를 **모두** 시도하고 교차 검증한다.

**모드 A — 저장소 접근 가능**
`package.json` · `build.gradle` · `Podfile` · `pubspec.yaml` · `requirements.txt` · `go.mod` · CI 설정 · 환경변수 **키 이름만**(값 금지) 확인.

**모드 B — 저장소 없음 (외부 지문)**

```bash
# --- 웹 ---
for u in / /silove /silovematch /silovematch-consult /blinddate; do
  echo "=== $u"; curl -sSI "https://sinor.co.kr$u" | head -15; sleep 1
done
curl -sS https://sinor.co.kr | head -c 30000        # 메타·번들 경로·인라인 스크립트
curl -sS https://sinor.co.kr/robots.txt
curl -sS https://sinor.co.kr/sitemap.xml | head -60
curl -sSI https://msinor.hanatour.com/dcr/
dig +short sinor.co.kr; dig +short CNAME sinor.co.kr; dig +short TXT sinor.co.kr
curl -sS "https://crt.sh/?q=%25.sinor.co.kr&output=json" | head -c 4000   # 서브도메인 열거
curl -sSI https://sinor.co.kr/.well-known/assetlinks.json                 # Android App Links
curl -sSI https://sinor.co.kr/apple-app-site-association                  # iOS Universal Links

# --- 앱 (APK 확보 시) ---
unzip -l app.apk | grep -Ei 'index.android.bundle|libflutter|libhermes|main.jsbundle|cordova|capacitor'
aapt dump badging app.apk | head -40
unzip -p app.apk res/xml/network_security_config.xml 2>/dev/null
strings app.apk | grep -Eo 'https?://[a-zA-Z0-9./_-]+' | sort -u | head -80   # API 호스트 추출
```
