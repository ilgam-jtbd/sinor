# 프로토타입 GitHub Pages 배포 안내 (2026-08-08 갱신)

> **용도** — `prototype/index.html`을 GitHub Pages로 공개해 디자이너·개발자·이해관계자가 링크로 열어보게 합니다.
> 빌드 도구 없이 그대로 호스팅되는 정적 페이지 배포 방식입니다.
> **2026-08-08 전면 갱신** — 저장소 실상태(기본 브랜치·비공개 저장소·대외비 문서 동거) 반영. 이전 안내의 "main 병합" 단계는 불필요해져 삭제.

## 0. 먼저 알아야 할 사실 3가지

| 사실 | 확인 근거 | 배포에 미치는 영향 |
|---|---|---|
| 이 저장소의 **기본 브랜치가 `claude/learning-session-b0yeka`** | GitHub API 조회 | main 병합 불필요. 배포 대상 브랜치만 지정하면 됨 |
| 저장소가 **비공개(private)** | GitHub API 조회 | 무료 플랜에서는 비공개 저장소 Pages 불가 → §2 참고 |
| **Pages 사이트는 항상 공개**(URL 아는 누구나 접속) | [GitHub 공식 문서](https://docs.github.com/en/pages/getting-started-with-github-pages/about-github-pages) | 저장소가 비공개여도 **배포된 파일은 전부 공개됨** → §1 경고 필수 |

## 1. ⚠️ 그대로 켜면 안 되는 이유 — 대외비 유출

Pages를 「Deploy from a branch → `/` (root)」로 켜면 **저장소의 모든 파일이 공개 URL로 노출**됩니다. 이 저장소에는:

- `docs/03_정합기준_정본_2026-08.md` — **매출·비용·CAC·재결제율 등 대외비 전수**
- `docs/incoming/` — 코워크 전략 원본
- 진단 보고서·IR 관련 수치 일체

가 들어 있어, `https://ilgam-jtbd.github.io/sinor/docs/03_정합기준_정본_2026-08.md` 식으로 **누구나 열람 가능**해집니다. 폴더 선택지는 `/(root)`와 `/docs` 둘뿐이라 docs 제외가 불가능합니다.

**해결 — 프로토타입만 담은 전용 브랜치(`gh-pages`)를 만들어 그 브랜치만 배포합니다.**
(CC가 승인받아 생성 — `index.html` 1개 파일만 orphan 브랜치에 둠. 대외비 문서는 브랜치에 아예 없음)

## 2. 비공개 저장소 + 무료 플랜 문제

GitHub **Free 플랜은 공개 저장소만 Pages 지원**입니다 ([플랜별 지원표](https://docs.github.com/en/get-started/learning-about-github/githubs-plans)). `ilgam-jtbd` 계정이 Free라면 Settings→Pages에 업그레이드 안내가 뜹니다. 선택지:

| 선택지 | 비용 | 절차 |
|---|---|---|
| **A. GitHub Pro 업그레이드** (권장) | 월 $4 | [github.com/settings/billing/plans](https://github.com/settings/billing/plans)에서 Pro 결제 → 비공개 저장소 그대로 Pages 사용 |
| B. 프로토타입 전용 **공개 미니 저장소** 신설 | 무료 | CC가 `sinor-prototype` 공개 저장소를 만들어 index.html만 push (대외비 없음) |

## 3. 배포 절차 (사람이 GitHub 웹에서 — 5분)

전제: §1의 `gh-pages` 브랜치가 준비된 뒤.

1. **[github.com/ilgam-jtbd/sinor/settings/pages](https://github.com/ilgam-jtbd/sinor/settings/pages)** 접속 (Settings → Pages)
2. **Build and deployment → Source**: `Deploy from a branch` 선택
3. **Branch**: `gh-pages` · 폴더 `/ (root)` → **Save**
4. 1~2분 후 상단에 초록색 배너로 배포 URL 표시:
   **`https://ilgam-jtbd.github.io/sinor/`**
5. 링크 접속 확인 후 디자이너·개발자·대표님께 공유

배포가 안 보이면: 저장소 [Actions 탭](https://github.com/ilgam-jtbd/sinor/actions)에서 `pages-build-deployment` 워크플로 성공 여부 확인.

공식 매뉴얼: [Configuring a publishing source](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## 5. 갱신 배포

`gh-pages` 브랜치의 index.html을 교체 push하면 1~2분 내 자동 재배포됩니다. (CC에 "프로토타입 Pages 갱신"이라고 요청하면 수행)

## 6. 커스텀 도메인(선택)

`prototype.sinor.co.kr` 연결 시: Pages 설정의 Custom domain에 입력 + DNS에 CNAME(`prototype` → `ilgam-jtbd.github.io`) 추가. 실서비스 본 도메인 색인에 영향 없게 서브도메인만 사용. ([공식 안내](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site))
