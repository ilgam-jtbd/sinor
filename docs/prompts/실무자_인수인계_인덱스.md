## 지금 확정된 것 — 8줄 요약

1. 성공지표 **1순위 = 매출**, 2순위 = 앱 설치 (단, **착수 1순위는 측정 부착**)
2. 웹 히어로 = **매출 CTA**(무료 인연 상담 · 단체미팅 신청)
3. 구역마다 **목표 배지** — 만남·여행=매출(앱 유도 없음) / 모임·칼럼=앱 설치 / 자녀=공유
4. 만남 = **1:1 · 단체미팅 · 시럽인연** 3분기 + **공감 배지**(마리슈 벤치마크)
5. **칼럼 유지**, 후기는 만남 뒤 사회적 증거로
6. 앱 다운로드 = **헤더 칩 + 스크롤 하단 고정 바**
7. **앱 내 웹뷰**에서는 설치 유도 전부 숨김 (`web.sinor.co.kr` — 역컴파일로 확인)
8. **이벤트 2종** 상시 — 친구초대 5,000원 · 모임개설 11만P
