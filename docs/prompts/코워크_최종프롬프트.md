## 3. 확정 사항 10가지 — 네 문서 모두 이것과 일치해야 합니다

**아래는 전부 확정입니다. "검토 중"·"제안"으로 표기하지 마십시오.**

1. **성공지표 1순위 = 매출 전환** (결제·상담·신청 완료). 앱 설치 유도 도달률(1.4%→5%)은 **2순위**. 【대표 확정】
   - 단, **착수 1순위는 "측정 부착"**입니다. 결제 완료가 7개월 20건만 잡히는 상태에서는 매출을 판정할 수 없습니다. 측정이 배포보다 먼저입니다.
2. **웹 홈 히어로 = 매출 CTA** (무료 인연 상담 · 단체미팅 신청). 히어로에 앱 설치 버튼을 넣지 않습니다.
3. **페이지별 단일 목표를 화면에 "목표 배지"로 명시.**
   - 만남·여행 = **매출** (앱 유도 없음) / 모임·칼럼 = **앱 설치** / 자녀 타깃 = **공유**
   - 전 페이지에 같은 앱 버튼을 다는 것은 금지입니다(전환을 깎습니다).
4. **만남 = 1:1(시럽) · 단체미팅 · 시럽인연(결혼·재혼)** 3분기.
   - **공감 배지** 추가 — 재혼 이해 / 자녀 이해 / 사별 공감.
   - 일본 **마리슈(marrish) 「리본 마크」** 벤치마크. 핵심은 **본인이 스스로 다는 신호**이며 시스템이 붙이는 낙인이 아닙니다. 선택형이고, 달지 않은 회원이 불이익을 받지 않습니다.
5. **칼럼 명칭 유지.** 후기(우리들의 이야기)는 별도 메뉴로 만들지 않고 **만남 블록 직후 사회적 증거**로 배치합니다(성혼·매칭 후기 → 상담 전환 기여). 칼럼은 시니어칼럼 191편(검색 유입 엔진 + 글 하단 전환 카드).
6. **앱 다운로드 = 2순위 CTA.** 상담·결제 흐름은 침범하지 않되 항상 닿게:
   - ① 헤더 우측 **「앱 설치」 칩**(상시) ② 스크롤 시 **하단 고정 다운로드 바**(닫기 가능)
7. **웹은 두 맥락으로 존재** 【APK 역컴파일로 확정】 — 앱이 **`web.sinor.co.kr`를 웹뷰로 임베드**합니다.
   - **웹 단독**: 주소창 · 설치 칩 · 고정 다운로드 바 노출
   - **앱 내 웹뷰**: 앱 헤더(‹ 시놀 ✕)로 바뀌고 **설치 유도 전부 숨김** — 이미 앱 안인 사용자에게 설치를 권하지 않습니다. 목표는 상담·신청·결제 완결
8. **앱 하단탭 = 4개 확정** (홈·여행·만남·모임). **칼럼 탭을 신설하지 않습니다.** 【대표 확정】
   - 칼럼 글 배치: **홈 「칼럼·정보」 섹션** + 주제별 맥락 메뉴(건강→모임 / 재혼→만남 / 여행→여행)
9. **이벤트 2종 상시 노출** (기간 한정 아님) 【대표 확정】 — 히어로 매출 CTA **바로 아래** 2분할 배치
   - **친구초대 5,000원 서로 받기** → `https://sinor.co.kr/?utm_source=app&utm_medium=invite&utm_campaign=inviteFriendsByLink` (**utm 파라미터 원형 보존**)
   - **모임개설 11만 포인트** → 모임 섹션에도 강조 배너로 이중 배치
   - 문구는 맥락별로: 웹 단독 「앱 받고 초대하기 / 앱에서 개설하기」 · 앱 내 웹뷰 「친구 초대하기 / 모임 개설하기」
   - **개인정보 주의**: 위 3개 파라미터는 순수 캠페인 태그로 개인정보가 없습니다. 다만 실제 발급되는 초대 링크에 **초대 코드(식별자)**가 붙는 경우, 그 값이 GA4·로그에 원문으로 적재되지 않도록 마스킹/해시 처리합니다.
10. **실측 개발 스택** 【APK 역컴파일로 확정】 — 개발 문서의 스택 표를 이것으로 교체
    - 공통: **Flutter(Dart AOT) + Kotlin**, minSdk 24 / target 36, **Easemob 채팅**, Firebase(FCM·Crashlytics·RemoteConfig, 프로젝트 `sinor-8b864`), **S3(서울) + CloudFront**, **Adrop 광고 스플래시가 런처**
    - 시놀: AppLovin · ByteDance Pangle · Adrop · AdMob 광고, **TossPayments**(웹결제), Facebook 로그인
    - 시럽: **Agora RTC**(화상), **ML Kit Face**(안면인증), **TossPayments + Play Billing v8**, 민감권한(정밀위치·연락처·마이크·전화상태)
    - **한계 명시**: 비즈니스 로직은 Dart AOT라 소스 복원 불가 — 스택·권한·엔드포인트만 확정

## 5. 정합 규칙 (어기면 반려)

1. **수치는 정합기준 정본이 유일 출처.** 문서 간 숫자가 다르면 정본에 맞춥니다. **새 숫자를 만들지 않습니다.**
2. **앱 유도 = 시놀 앱 단일.** 시럽 앱 유도는 `/silove` 내부에서만 + 성인(18+) 병기. **시럽인연 상담·여행 결제 페이지에는 앱 유도 금지.**
3. **수익 카드**는 콘텐츠 카드와 **동일 컴포넌트** — 별도 테두리색·배경색·「광고」 표기 금지. 3종 연속 배치 금지.
4. **접근성**: 본문 최소 17px · 터치 영역 최소 48px · 명도 대비 4.5:1.
5. **미확인 항목은 비우지 않습니다** — "미확인 — 확인 방법"을 적습니다.
6. **추측을 사실로 쓰지 않습니다.** 확정/유력/추정/미확인 4단계로 표기합니다.
