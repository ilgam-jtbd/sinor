# V3 개편 — OpenAI Codex 실행 프롬프트

**언제 쓰나** — 명확히 정의된 단일 작업: 컴포넌트 구현·이벤트 부착·스타일·정형 변환.
Codex는 파일 경로·입출력·완료 조건을 못 박아야 결과가 좋습니다. 조사·구조 변경은 `개발프롬프트_V3_ClaudeCode.md`가 담당합니다.

> **전제** — Claude Code가 Phase 0 조사로 `IMPLEMENTATION_PLAN.md`를 만든 뒤에 씁니다. 파일 경로는 그 계획에서 확정된 값으로 채웁니다. 계획 없이 Codex에 넘기면 경로를 추정해 엉뚱한 파일을 고칩니다.

---

## 공통 제약 (AGENTS.md 준수)

- 테두리색·배경색·「광고」 표기 금지 (수익 카드는 콘텐츠 카드와 동일 컴포넌트)
- 가격 하드코딩 금지 — props로 받은 실제 값만
- 본문 17px · 터치 48px · 명도 대비 4.5:1
- 기존 인터페이스 유지 · 이벤트를 같은 작업에 부착 · 임의 확장 금지

## 예시 1 — 하단 4대 메뉴 네비게이션

```
파일: [IMPLEMENTATION_PLAN.md에서 확정한 navigation 컴포넌트 경로]
작업: 하단 네비게이션을 홈/여행/만남/모임 4개 탭으로 교체

입력: 현재 route 정의 (홈/여행/만남/모임에 매핑할 기존 화면 route)
출력: 4탭 하단 네비 + 우측 상단 마이페이지 진입 버튼

요구사항:
- 4탭: 홈 · 여행 · 만남 · 모임 (한글 라벨, 아이콘 병기)
- 우측 상단: '마이페이지' 텍스트 + 사람 아이콘 ('마이' 단독 명칭 금지)
- 활성 탭 색상 구분, 라벨 크기는 활성/비활성 동일 (굵기로만 구분)
- 터치 영역 48px 이상

제약:
- 기존 route를 재사용한다. 새 route를 만들지 않는다
- 채팅 탭을 제거하되 채팅 화면 route 자체는 삭제하지 않는다 (맥락 진입으로 유지)

완료 조건:
- [ ] 4탭 렌더 + 마이페이지 진입 동작
- [ ] 이벤트: primary_nav_tap(menu=home|travel|meet|groups) · mypage_open(entry_point)
- [ ] 360/390/430px에서 라벨 겹침 없음
```

## 예시 2 — 수익 카드 컴포넌트 (홈/만남/여행 공용)

```
파일: [수익 카드 컴포넌트 경로]
작업: 수익 카드 3종을 콘텐츠 카드와 동일 컴포넌트로 구현

입력:
  cardType: 'meeting' | 'diagnosis' | 'trip'
  title, subtitle, ctaLabel, ctaTarget
  badge?: string          // 잔여 3석 이하일 때만
  listPrice?, memberPrice? // trip일 때만
  imageUrl?               // 없으면 cardType별 기본 이미지

출력: 콘텐츠 카드와 시각적으로 구분되지 않는 카드

요구사항:
- 콘텐츠 카드와 동일 컴포넌트·동일 위계
- trip: 정가 취소선 + 멤버십가 강조, props 값만 사용
- badge 있을 때만 강조 표기

완료 조건:
- [ ] 콘텐츠 카드와 나란히 놓았을 때 구분 안 됨
- [ ] 이벤트: revenue_card_impression(card_type, position) / revenue_card_tap(card_type, cta_label)
- [ ] badge 유무·imageUrl 유무 각 경우 렌더 확인
```

## 예시 3 — 만남 목적 선택 화면

```
파일: [만남 메뉴 화면 경로]
작업: 만남 진입 시 목적 선택 UI 구현

출력: "어떤 만남을 찾으세요?" + 3개 목적 카드
  - 친구를 만나고 싶어요 → 시럽 (성인 등급 안내 병기)
  - 진지한 인연을 찾고 싶어요 → 시럽인연 (인연진단→상담→전화)
  - 함께 만나요 → 단체미팅 (일정·지역·잔여석)

요구사항:
- 각 카드는 기존 시럽/시럽인연/단체미팅 route로 연결
- 시럽 카드에 성인 등급(Play 18+) 안내 문구
- 시럽인연 카드 탭 시 인연진단으로, 결과 화면에 전화 상담 원탭

완료 조건:
- [ ] 3개 목적 카드 렌더 및 각 route 연결
- [ ] 이벤트: primary_nav_tap(menu=meet) · diagnosis_complete · consult_call_tap(entry_point)
```
