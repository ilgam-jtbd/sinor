## 1. 링크 표준 블록 — 영상 설명란용 (UTM 포함)

아래를 **그대로 복사**해 쓰고, `{{슬러그}}` 자리만 영상별로 바꿉니다.

```
▶ 시놀 홈페이지
https://sinor.co.kr/?utm_source=youtube&utm_medium=description&utm_campaign={{슬러그}}

▶ 시럽인연 (프리미엄 결혼정보 · 성혼비 없음)
https://silovematch.sinor.co.kr/?utm_source=youtube&utm_medium=description&utm_campaign={{슬러그}}

[시놀 앱 — 5060 모임·동호회·오늘의운세]
· Android : https://play.google.com/store/apps/details?id=com.sinor.gathering
· iOS : https://apps.apple.com/kr/app/id6503413274

[시럽 앱 — 50+ 이성친구 만남 · 만 19세 이상]
· Android : https://play.google.com/store/apps/details?id=com.sinor_app_front
· iOS : https://apps.apple.com/kr/app/id6474283649
```

### 규칙

- **UTM은 웹 링크에만.** 스토어 링크에는 붙이지 않습니다(스토어는 자체 파라미터 체계를 씁니다).
- **UTM은 외부 유입에만.** 내부 페이지 링크에 붙이면 canonical이 흔들립니다(코드 7계층 ⑥ 내부링크 원칙과 상충).
- **시럽 링크에는 연령 안내를 병기.** App Store 실물 등급이 **19+**(Play 18+)이며 "성적인 내용 또는 노출" 표시가 붙어 있습니다. CLAUDE.md §6이 요구한 18+ 병기를 **19+로 갱신**해야 정확합니다.
- **블록 형태를 매번 바꾸지 않습니다.** 같은 형태의 반복이 엔티티 신호를 만듭니다.

### UTM 캠페인 슬러그 규칙

`{{주제}}-{{연월}}` 형식, 영문 소문자·하이픈.

| 주제 | 슬러그 예 |
|---|---|
| 5060 만남·소개팅 | `meet5060-202609` |
| 모임·동호회 | `club5060-202609` |
| 오늘의 운세 | `fortune-202609` |
| 재혼·시럽인연 | `remarriage-202609` |
| 시놀트립 | `trip-202609` |

## 2. 웹 상세페이지용 — sameAs JSON-LD

`sinor.co.kr` **홈 `<head>`에 1회만** 삽입합니다. 하위 페이지에 중복 삽입하지 않습니다.

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Organization",
  "name": "시놀",
  "legalName": "시놀(주)",
  "url": "https://sinor.co.kr",
  "logo": "https://sinor.co.kr/{{로고_절대URL}}",
  "description": "50+ 시니어를 위한 모임·만남 플랫폼. 5060 동호회, 이성친구 만남, 재혼 상담을 운영합니다.",
  "sameAs": [
    "https://play.google.com/store/apps/details?id=com.sinor.gathering",
    "https://apps.apple.com/kr/app/id6503413274",
    "https://play.google.com/store/apps/details?id=com.sinor_app_front",
    "https://apps.apple.com/kr/app/id6474283649",
    "https://silovematch.sinor.co.kr"
  ],
  "contactPoint": {
    "@type": "ContactPoint",
    "telephone": "+82-2-508-5670",
    "contactType": "customer service",
    "areaServed": "KR",
    "availableLanguage": "Korean"
  }
}
</script>
```

- `logo`는 **절대 URL 필수**(상대경로면 인식 실패).
- 삽입 후 **리치결과 테스트**로 오류 0건 확인.
- 이 스키마는 로드맵 2단계(리치결과)와 같은 작업이라 **FAQPage 스키마와 함께 한 번에** 처리하는 것이 효율적입니다.

아무 주제나 올리지 않습니다. **시놀 = 이 주제**로 검색·AI가 엮도록 실제 서비스 주제로만 만듭니다.

|---|---|---|---|---|
| 1 | 5060 만남 | 5060 소개팅, 중년에 친구 만드는 가장 안전한 방법 | 시놀 앱 | `meet5060-202609` |

| 3 | 오늘의 운세 | 오늘의 운세·띠별 운세 무료로 보는 법 (5060 앱) | 시놀 웹 `/fortune` | `fortune-202609` |
| 4 | 재혼 | 결정사 비용이 부담될 때 — 5060 재혼 상담 성혼비 없이 | 시럽인연 | `remarriage-202609` |

**설명란 구성** — ① 3줄 요약(첫 문장에 답) → ② 링크 표준 블록 → ③ 타임스탬프 → ④ 해시태그 5개 이내.

### 6-3. Organization sameAs — 제외

처음에는 "같은 회사 앱이니 넣는 게 정확하다"고 볼 수 있지만, 조사해 보니 반대입니다.

- **독립 도메인이 이미 있습니다.** `heartlink.kr`이 운영 중입니다. 자체 Organization 스키마를 갖는 편이 정확하고, 검색 권위도 각자 쌓입니다.
