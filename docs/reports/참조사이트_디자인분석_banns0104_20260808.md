| 바탕 | 근백색 캔버스(`#FAFBFC`/`#FBFBFB`) + 순백 서피스. 회색 과다 금지 |

## 2. 시놀에 그대로 가져온 것

- **Pretendard + Source Code Pro** CDN 로드 (참조 사이트와 동일 방식)
- radius 10/14/20, 다층 소프트 섀도우 sm/md/lg
- 모노 대문자 **eyebrow**(Today·Meeting·Travel…)로 섹션 리듬
- `135deg` 그라디언트 히어로 카드 + **라디얼 글로우**
- 카드 좌측 4px 악센트(만남 목적 카드), stat 타일 **모노 수치**
- **pulse**(잔여석 라이브 점), **fadeInUp**(섹션 진입), backdrop-blur 헤더·탭바
- 진행바 그라디언트, 필 칩, 폰 프레임 + 노치

## 3. 시놀에 맞게 바꾼 것 (의도적 결정)

| 항목 | 하우스 | 시놀 | 이유 |
|---|---|---|---|
| **브랜드색** | 일렉트릭 블루 `#0041FF` | **딥틸 `#0F6E68` + 감빛 코랄 `#E8683D`** | 브랜드색은 제품마다 유연(TimeBid=레드가 증명). 시놀은 시니어 **신뢰(틸)+온기(코랄)**. VELOR 블루를 그대로 쓰면 시놀 정체성이 안 생김 |
| **본문 크기** | 11~14px(밀도 높음) | **17px+** | 시니어 접근성. 하우스의 밀도는 젊은 B2B 대상. 시놀은 5060이 주 사용자 |
| **터치 영역** | — | **48~52px** | 동일 이유 |
| 톤 | 데이터 밀집 B2B | 따뜻한 생활 플랫폼 | 5060 생활 서비스에 맞는 온도 |

**핵심** — 하우스 스타일의 *실행 방식*(폰트·섀도우·radius·모션·히어로·카드 패턴)은 그대로 가져오되, *색과 크기*는 시놀 사용자(5060)와 정체성(신뢰+온기)에 맞게 바꿨습니다. 참조를 베낀 게 아니라 **같은 문법으로 시놀을 쓴** 것입니다.

## 4. 미적용 — 시놀에 안 맞아 제외

- 글래스모피즘 칩(aichat) — 시니어 명도 대비에 불리
- 900 초굵은 42px 디스플레이(aichat) — 시니어에겐 과함, 800으로 절제
- CCTV/맵 스캔 모션(fishing) — 시놀 도메인과 무관
- 극단적 음수 자간(-2px) — 가독성 저하
