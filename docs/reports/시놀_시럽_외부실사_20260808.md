## 0. 조사 요약

**가장 중요한 발견 3가지**

1. **개발요구서 v1.0의 URL 판정 3건이 실제와 다릅니다.** 단체미팅·칼럼·앱 다운로드 모두 독립 URL이 **이미 존재**합니다. "신설"이 아니라 "있는데 안 쓰고 있는" 문제이며, 이는 요구사항의 성격과 공수를 바꿉니다
2. **웹 플랫폼은 아임웹(Imweb)으로 유력합니다.** 칼럼 URL 패턴 `?bmode=view&idx=`가 아임웹 게시판 규격이고, `doz_` 접두도 아임웹 전신(DOZ)의 흔적입니다. 사실이면 `<head>` 태그 삽입·페이지별 SEO·GTM 설치가 **가능**하므로 Q7의 최악 시나리오(폐쇄형 빌더)는 피합니다
3. **시럽인연의 진짜 차별점은 가격이 아니라 「성혼비 없음」입니다.** 시장 관행이 성혼비 100~500만원 별도 과금인데, 300~400만원 총액 완결은 구조가 다릅니다. 현재 랜딩에서 이 메시지가 최상단에 없습니다

**개발 착수를 막는 요인 3가지**

1. `/meeting`이 언제부터 있었고 홈 앵커(`#doz_menu_meeting`)와 어떤 관계인지 미확인 — 이것이 정해져야 광고 랜딩 이관을 결정할 수 있습니다
2. 단체미팅 참가비가 **99,000~300,000원으로 3배 편차** — 단일 구독 설계가 성립하지 않습니다. 가격 체계 재정의가 선행입니다
3. iOS 앱 ID 두 개의 앱 귀속이 검색 결과에서 엇갈립니다 — ASO 작업 대상을 확정할 수 없습니다

## 1. 사이트 구조 — 개발요구서 정정 필요

### 1-1. 판정이 뒤집힌 항목

| 개발요구서 v1.0 판정 | 외부 실사 결과 | 신뢰도 |
|---|---|---|
| 단체미팅 — **독립 URL 없음**, 홈 앵커(`#doz_menu_meeting`) | **`sinor.co.kr/meeting` 존재** — 제목 「그 시절 추억의 단체미팅」, 검색엔진에 색인됨 | 확정 |
| 칼럼 — **경로 미확인** | **`sinor.co.kr/information`** (상세: `/information/?bmode=view&idx={번호}`) | 확정 |
| 앱 다운로드 — **경로 미확인** | **`sinor.co.kr/download`** — 제목 「시놀 앱 다운로드」 | 확정 |

### 1-2. 새로 확인된 페이지·자산

| 경로 | 제목 | 전략적 의미 |
|---|---|---|
| `/adv` | 시놀 - 앱 광고상품 | **T2 「광고 인벤토리 패키지화」가 이미 페이지로 존재.** 건강·먹거리·스포츠·패션·뷰티·여행·문화·교육·금융 분야 광고주 대상 |
| `/moim` (`www.` 포함) | 시놀 - 모임 찾기 | 모임 목록의 웹 진입점 |
| `/jeju` | 시놀 X 켄싱턴 리조트 & 호텔 | 여행 상품의 시놀 도메인 랜딩이 이미 있음 |
| `/silovematch_event` | 시럽인연 이벤트 | 시럽인연 프로모션 랜딩 |
| `/company` | 시놀 회사소개 | — |
| `web.sinor.co.kr` | 시놀 | **서브도메인 존재** — 용도 미확인 |

**해석.** 개발요구서는 "만들어야 할 것"으로 적었지만 실제로는 **만들어져 있고 연결·측정·광고 랜딩에 쓰이지 않는** 상태입니다. 종합전략 v3의 진단 문장("새로 만들 것보다 이어붙일 것이 많다")이 URL 층위에서도 그대로 맞습니다.

**즉시 확인 필요**
- `/meeting`의 생성 시점과 홈 앵커와의 관계 (중복 콘텐츠인지, 앵커가 이 페이지로 가는지)
- `/meeting`이 GA4에서 별도 페이지뷰로 잡히는지 — 잡힌다면 "조회 1,480·이탈 12.0%"의 귀속이 달라집니다
- `web.sinor.co.kr`의 용도와 색인 상태 (중복 색인이면 SEO 손실)
- `/jeju`와 `msinor.hanatour.com/dcr/`의 관계 — 시놀 도메인 랜딩이 있는데도 이탈 72.7%인지

### 1-3. 플랫폼 지문 — Q7 부분 회신

| 근거 | 판정 |
|---|---|
| 칼럼 상세 URL이 `?bmode=view&idx=167192834` 형식 | 아임웹(Imweb) 게시판 URL 규격과 일치 |
| 요소 식별자 `doz_` 접두 | 아임웹 전신 서비스명(DOZ)의 흔적 |

**판정: 아임웹(Imweb) — 유력.** 확정 시 의미는 다음과 같습니다.

- `<head>` 커스텀 코드 삽입 **가능** → 스마트 앱 배너(A1)·GTM·전환 스크립트·JSON-LD 전부 실현 가능
- 페이지별 `<title>`·메타 개별 지정 **가능** → W6 해소
- 다만 **URL 구조 자유도는 낮습니다** — `/silove`·`/silovematch` 접두 충돌(Q3)은 아임웹에서 리다이렉트 설계가 제한적일 수 있어, 분석 도구 필터 교체로 대응하는 기존 권고가 여전히 맞습니다

**확인 방법**: 페이지 소스에서 `imweb`/`doz` 문자열, 응답 헤더의 `server`/`x-powered-by`, 어드민 로그인 URL. 개발자에게 "아임웹 맞는지, 코드 삽입 권한이 우리에게 있는지" 두 줄만 물으면 끝납니다.

## 2. 앱·ASO 실사

### 2-1. 스토어 제목 — 즉시 고칠 수 있는 가장 싼 개선

| 앱 | 현재 Play 제목 | 문제 |
|---|---|---|
| 시놀 | `시놀 - 50+ 친구만들기&모임 취미 동호회` | **'5060' '중년' '시니어' '단체미팅'이 제목에 없습니다.** 사용자가 실제로 검색하는 말과 다릅니다 |
| 시럽 | `시럽 - 중장년 안심 데이트 & 이성 만남 앱` | '중장년' '안심'이 들어가 있어 상대적으로 낫습니다 |

'50+'는 회사가 쓰는 말이고, 사용자는 '5060' '중년' '시니어'로 검색합니다. GA4 실측에서 유입을 만든 키워드군(단체미팅·중년 소개팅·5060 모임)이 앱 제목에 하나도 없습니다. **제목·부제 수정은 스토어 콘솔 접근만 있으면 하루 안에 끝납니다.**

### 2-2. iOS 앱 ID 귀속 충돌 — 확인 필요

검색 결과에서 같은 ID가 서로 다른 앱으로 표시됩니다.

| ID | 표기 A | 표기 B |
|---|---|---|
| `6474283649` | 「시럽 앱 - App Store」 | 「App Store에서 제공하는 시놀」 |
| `6503413274` | 「시놀 앱 - App Store」 | — |

기존 정합기준은 시놀=6503413274, 시럽=6474283649로 잡고 있습니다. **ASO 작업 대상을 확정하려면 두 ID의 실제 앱을 먼저 확인해야 합니다.** 앱 이름이 중간에 바뀌었을 가능성도 있습니다. (신뢰도: 미확인 — 스토어 콘솔 또는 실기기 확인 필요)

### 2-3. 브랜드 메시지 — 이미 강한 자산이 있습니다

공개 자료에서 반복 노출되는 메시지입니다.

- **5중 AI 「여성안심」** — 안면 본인인증 · 키워드 필터링 · 24시간 모니터링 · 신고·차단 · 행동분석
- **AI 실시간 안면 인식 사진 검증** — 복잡한 본인인증을 대체
- 로맨스스캠·피싱 차단

**모순 지점.** 이 메시지가 스토어 「데이터 안전」 카드의 *암호화되지 않음*, 시럽의 *개인정보·금융정보 제3자 공유* 표시와 정면으로 충돌합니다. 사기를 가장 두려워하는 사용자층에게 **웹에서 쌓은 신뢰가 스토어에서 무너집니다.** 데이터 안전 재제출이 ASO 항목 중 우선순위 1번인 이유입니다. (기존 진단 재확인 — 신뢰도: 확정)

## 3. 상품 실체 — 단체미팅

### 3-1. 확인된 가격·구성

| 항목 | 확인 내용 | 신뢰도 |
|---|---|---|
| 참가비 | **99,000원 ~ 300,000원대** | 유력 |
| 형태 | 1박 2일 글램핑(경기 성남) · 종교 테마 · 여행 테마 · 해외 휴양(나트랑) | 확정 |
| 포지셔닝 | 「국내 최초 품격있는 중년의 만남」 · 5060 싱글 대상 | 확정 |
| 상품군 | 「단체미팅 3종세트」로 패키지화되어 언론 노출 | 확정 |

### 3-2. 구독 설계에 대한 경고 — 기획서 재검토 필요

종합전략 v3 S9는 구독 가격 원칙을 **「단품 2회 값 ≈ 구독 3개월」**로 정했습니다. 실제 가격을 대입하면 문제가 드러납니다.

| 기준 단품가 | 단품 2회 | 구독 3개월 환산 | 월 구독료 |
|---|---|---|---|
| 99,000원 (최저가) | 198,000원 | 198,000원 | **66,000원** |
| 300,000원 (최고가) | 600,000원 | 600,000원 | **200,000원** |

**월 66,000원도 시니어 구독료로는 높고, 200,000원은 성립하지 않습니다.** 참가비가 3배 편차인데 단일 구독으로 묶으면, 구독자는 최고가 상품만 신청해 역마진이 나거나, 저가 상품만 커버하면 구독의 매력이 사라집니다.

**권고 — 구독 설계 전에 상품 등급을 먼저 나눕니다.**
- 구독이 커버하는 것: **기본 참석권(도심 당일형, 99,000원대)** 월 1회 + 우선 예약 + 이월
- 구독에서 제외: 1박 2일 글램핑·해외 미팅여행 등 원가가 다른 상품 → **구독자 할인율**로 연결
- 이렇게 하면 구독료를 월 3만원대로 낮출 수 있고, 고가 상품은 구독자 전환의 업셀 경로가 됩니다

이는 v3 S9의 원칙을 뒤집는 것이 아니라, **원칙을 실제 가격표에 적용했을 때 나오는 구체화**입니다. 개발 착수 전 사업 확정이 필요합니다.

## 4. 시럽인연 가격 포지셔닝 — 시장 대조

### 4-1. 결혼정보 시장 관행

| 구분 | 시장 가격대 | 출처 성격 |
|---|---|---|
| 일반 프로그램 | 100~300만원 (1년 5회 소개 기본) | 업계 공개 정보 |
| 일반 가입비 통상 범위 | 200~500만원 | 업계 공개 정보 |
| 노블레스 | 300~500만원 | 업계 공개 정보 |
| VIP | 1,000~3,000만원 | 업계 공개 정보 |
| **50대 재혼 특화** | **1,000만원 이상 견적 사례** | 상담사 언급 |
| **성혼비(성공 보수)** | **별도 100~500만원 추가** | 업계 관행 |

신뢰도: 유력 (공개 비교 콘텐츠 기반, 개별 업체 실계약가는 미확인)

### 4-2. 시놀의 위치

시럽인연 300~400만원은 **가격대 자체로는 시장 중간**입니다. 「경쟁사 대비 절반」이라는 v3 표현은 노블레스~VIP 구간과 비교할 때만 맞습니다.

**진짜 차별점은 총액 구조입니다.** 시장 관행이 가입비 + 성혼비 100~500만원 별도인데, 성혼비가 없으면 실질 부담이 40~60% 낮아집니다. 50대 재혼에 1,000만원 이상을 부르는 시장에서 **300~400만원 완결**은 다른 층위의 제안입니다.

**실행 권고**
1. 상담 랜딩 신뢰 블록의 **첫 줄을 「성혼비 없음」으로** 올립니다. 지금은 여러 신뢰 요소 중 하나로 묻혀 있습니다
2. 「총액 비교표」를 콘텐츠로 만듭니다 — 경쟁사 가입비+성혼비 vs 시럽인연 총액. 이탈률 7.0%의 상담 페이지에 붙일 수 있는 가장 강한 자산입니다
3. AEO 대응: "결혼정보회사 가격은?" "재혼 비용 얼마인가요?"는 이미 답변형 질문입니다. 이 표가 그대로 답이 됩니다

## 5. 경쟁 지형

| 경쟁자 | 성격 | 위협 수준 | 판단 |
|---|---|---|---|
| **당근 모임** | 지역 기반, 중장년 이용자 확대 중 | **최상** | CAC가 사실상 0이고 지역 밀도가 압도적입니다. 「지역 모임」으로 정면 경쟁하면 집니다. 시놀의 방어선은 **본인인증 신뢰 + 만남 목적 명시**입니다 |
| **오이** | 4060 취미모임·동호회·동네친구·문화모임 | 상 | 가장 직접적인 동일 세그먼트 경쟁. 앱 홈·채팅 탭 구조의 참고 대상이기도 합니다 |
| 문토 | 관심사 기반 커뮤니티 (독서·미술관·클래식·사진·영어) | 중 | 중장년 유입이 늘고 있으나 주 타깃은 더 젊습니다 |
| 러브캐스팅 | 단체미팅 직접 경쟁 | 중 | 단체미팅 상품의 실질 경쟁자 |
| 포페런츠 | 부모님 대상 (자녀가 구매) | 중 | **자녀 타깃 세그먼트의 직접 경쟁자.** 이탈률 7.7%로 사이트 최저인 구간인데 시놀은 콘텐츠가 1편뿐입니다 |

**전략적 함의.** 커뮤니티 층에서 당근·오이와 싸우는 것은 비용 경쟁입니다. 시놀이 이기는 층은 **매칭(시럽인연)** 이며, 커뮤니티는 그 매칭으로 가는 모객 엔진으로만 방어하면 됩니다. 종합전략 v3의 「입구-전환-확장」 구조가 경쟁 지형에서도 맞습니다.

| 특허 | 생성형 AI 기반 기술 특허 보유 | 확정 |

**주목할 점 두 가지**

1. **오프라인 모객이 초기 성장의 실제 엔진이었습니다.** 등산로·찜질방에서 가입자를 모았다는 것은, 가입 CAC 2,836원(계획값)이 온라인 광고만의 수치가 아닐 수 있다는 뜻입니다. CAC를 외부 문서에 쓸 때 **획득 채널 구성을 함께 밝혀야** 방어가 됩니다
2. **회원 증가율이 꺾였습니다.** 1년 만에 3만 → 2년 반 뒤 10.7만. 최근 월 신규 922~1,361명은 초기 속도의 회복이 아니라 감속 구간입니다. MAU를 신규로 지키는 경로가 닫혔다는 기존 판단과 일치합니다

## 9. 권고 — 권한 요청 전에 할 수 있는 일

개발자에게 권한을 요청하기 전에, **권한 없이 지금 확정할 수 있는 것**과 **권한이 필요한 것**을 나눠 두면 요청이 짧아집니다.

**권한 없이 이번 주 가능**
1. `/meeting`·`/information`·`/download`·`/adv` 네 페이지를 직접 열어 캡처 — 요구서 정정의 근거
2. 단체미팅 가격 등급 정리 → 구독 설계 재정의 (3-2)
3. 시럽인연 총액 비교표 작성 (4-2) — 콘텐츠·AEO 자산으로 즉시 사용
4. 스토어 제목·부제 개선안 초안 (2-1)

**개발자에게 요청할 권한 — 우선순위 순**

| # | 권한 | 무엇이 열리는가 | 요청 난도 |
|---|---|---|---|
| 1 | **GTM 계정 편집 권한** | 전환추적·GA4 이벤트·스마트 배너를 개발 배포 없이 붙일 수 있습니다. 측정 공백 해소의 핵심 | 낮음 |
| 2 | **GA4 속성 편집 권한** | 봇 필터·크로스도메인·전환 이벤트 설정 | 낮음 |
| 3 | **구글 서치콘솔 · 네이버 서치어드바이저 소유권** | 검색어를 처음으로 보게 됩니다. 모든 SEO 작업의 선행 조건 | 낮음 |
| 4 | **Play Console · App Store Connect 접근** | ASO 제목·부제·스크린샷·데이터 안전 재제출 | 중간 (외주 보유 시 인계 필요) |
| 5 | **웹 어드민(아임웹 추정) 편집 권한** | `<head>` 코드 삽입 · 페이지 메타 · 페이지 신설 | 중간 |
| 6 | 어드민 조회 권한 (상품·모임·회원 통계) | 단체미팅 가격·정원·마감 이력, 지역 정보 보유율 | 중간 |

**1~3번은 개발 공수가 들지 않는 계정 권한이며, 이것만 열려도 측정 공백의 대부분이 해소됩니다.** 개발자 일정과 무관하게 진행할 수 있으므로 가장 먼저 요청할 것을 권합니다.
