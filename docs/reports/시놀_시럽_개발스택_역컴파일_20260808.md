## 1. 한 줄 요약

**두 앱 모두 Flutter(Dart AOT) + Kotlin 호스트로 만든 단일 코드베이스 계열**입니다. 시놀은 **광고 수익형**(AppLovin·Pangle·Adrop), 시럽은 **실시간 화상·안면인증형**(Agora RTC + ML Kit Face + Play 결제/TossPayments)입니다. 둘 다 **Adrop 광고 스플래시로 앱이 시작**되고, **web.sinor.co.kr 웹뷰를 임베드**해 앱↔웹이 콘텐츠를 공유합니다.

## 9. 2026-08-09 정정·보강 (슬랙 `30_시놀_기획-개발` 대조)

### 9-1. 채팅 엔진 — 「아고라」와 Easemob은 같은 것입니다 【유력】

현장은 채팅을 **"아고라"**라고 부르고(김민지 7/27 「채팅 아고라 → 내부 시스템」, 최지영 우선순위 2 「아고라 → 신규 채팅 개발」), 본 보고서는 **Easemob/Hyphenate**로 적었습니다. 모순이 아닙니다 — **Agora Chat SDK가 Easemob(환신) 기술 기반**이라 Android 패키지명이 `com.hyphenate.*`로 남습니다. 화상·음성의 **Agora RTC와는 다른 제품**입니다(시럽의 RTC는 별개).

**확인 방법** — Agora 콘솔에서 Chat 프로젝트 App ID·SDK 버전 확인, 또는 `libagora*.so` / `io.agora.chat` 심볼 대조.

**실무 함의** — 최지영이 우선순위 2번 전체를 막아둔 질문(「기존 대화 데이터 이관 가능한가」)에 답할 경로가 생깁니다. Easemob/Agora Chat 계열은 서버에 메시지 이력을 보관하고 **REST API로 내려받는 경로가 존재**하는 것이 일반적이라 **이관 가능 쪽에 무게**가 실립니다 【추정 — 플랜·보관기간에 좌우】. 확인 순서: ① 현재 플랜의 **메시지 이력 보관 기간**(이게 상한) → ② History/Export API 사용 가능 여부·호출 한도 → ③ 1개 방 시험 추출로 스키마 확인 → ④ 마이그레이션 일정 확정. **보관 기간이 짧으면 「이관 가능」이어도 오래된 대화는 이미 없습니다.**
