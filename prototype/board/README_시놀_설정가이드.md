> 브랜딩·팀·서비스 구분은 시놀 기준으로 이미 반영돼 있고, 아래 3가지만 채우면 작동합니다. (약 15분)

## 1. Firebase 프로젝트 만들기 (무료)

1. https://console.firebase.google.com → 프로젝트 추가
2. **빌드 → Realtime Database** → 데이터베이스 만들기 (지역 선택, 잠금 모드로 시작)
3. **빌드 → Authentication** → 시작하기 → 로그인 방법에서 **Google** 사용 설정
4. 프로젝트 설정(⚙️) → 일반 → 내 앱 → **웹 앱 추가(</>)** → SDK 설정의 `firebaseConfig` 값 복사

> 시놀은 이미 Firebase 프로젝트(`sinor-8b864`)를 앱에서 쓰고 있습니다. 운영보드는 **별도 프로젝트로 새로 만드는 것을 권장**합니다 — 운영 데이터와 내부 협업 데이터를 섞지 않기 위함입니다.

## 2. index.html 설정 교체 (필수 3가지)

`index.html`을 열어 아래를 수정합니다.

1. **`YOUR_FIREBASE_API_KEY`** 검색 → `firebaseConfig` 블록을 1-4에서 복사한 값으로 교체
2. **`admin1234`** 검색 → 관리자 모드 비밀번호 변경 **(필수)**
3. **`TEAM` 배열**의 `email`을 실제 구글 로그인 계정으로 교체
   - 현재는 `ceo@sinor.co.kr` 형태의 자리표시자입니다
   - 시럽 매니저는 A·B 2명으로 두었습니다. 실제 인원수에 맞게 추가·삭제하세요
   - 구글 워크스페이스 계정이 아니면 실제 사용하는 지메일 주소로 넣어도 됩니다

> `sinor.co.kr` 도메인 이메일은 자동 로그인이 허용되고, 그 외 주소는 관리자가 예외 등록합니다.

## 3. Firebase 규칙 게시

Realtime Database → 규칙 탭에 `firebase_rules.json` 내용을 붙여넣고 게시합니다.

## 4. 배포

- **GitHub Pages 권장** — 저장소에 `index.html` 푸시 → Settings → Pages 활성화
- 배포 후 Firebase 콘솔 → Authentication → 설정 → **승인된 도메인**에 배포 도메인 추가
- 로컬 테스트: 폴더에서 `python3 -m http.server 8000` → `http://localhost:8000`

## 5. 첫 로그인

- TEAM에 등록한 이메일의 구글 계정으로 로그인
- 우측 상단 🔒 + 비밀번호로 관리자 모드 → 팀원 관리에서 권한(읽기/쓰기) 부여
- 관리자 메뉴 → "미디어 저장소 설정"에서 Cloudinary(무료 25GB) 연동 시 사진/동영상 100MB 원본 화질 업로드

## 6. 테스트베드 (운영 데이터 보호)

주소 뒤에 `?env=staging`을 붙이면 운영 데이터와 완전히 분리된 테스트 환경으로 열립니다.
좌하단 🧪 배너에서 "운영 데이터 복사" / "초기화"가 가능합니다.

- 회원 개인정보(이름·연락처)는 이 보드에 올리지 않습니다. 이슈에는 **회원 ID·화면 경로**만 적습니다
- 서버 비밀번호·API 시크릿은 어떤 필드에도 넣지 않습니다
- 대외비 원본 문서는 첨부하지 않고 링크로 참조합니다
