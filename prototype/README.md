# 시놀 프로토타입 — 4대 메뉴 (홈·여행·만남·모임)

시놀 V3 IA를 실제 콘텐츠로 구현한 **클릭 가능한 HTML 프로토타입**입니다.
와이어프레임(`docs/mockups/`)과 달리, 실제 색·문구·데이터가 들어간 동작 화면입니다.

- **파일**: `prototype/index.html` (단일 파일, 외부 의존 없음)
- **동작**: 상단 앱/웹 토글 · 하단 4대 메뉴 탭 전환 · 카드 클릭 이동 · 마이페이지 오버레이
- **데이터**: 정합기준 정본 실측 (회원 107,735명 · 모임 1,561개 · 시놀트립 49,900원/년 · 단체미팅 99,000원~ · 시럽인연 성혼비 없음)

## 로컬에서 보기

```bash
# 저장소 클론 후
open prototype/index.html          # macOS
# 또는 브라우저에 파일을 드래그
```

## GitHub Pages 배포

`docs/prompts/코워크_배포프롬프트_프로토타입.md`의 순서를 따르거나, 아래 요약대로 진행합니다.

1. GitHub 저장소 → **Settings → Pages**
2. Source: **Deploy from a branch**
3. Branch: `main` (또는 배포 브랜치) · 폴더: `/root` 또는 `/docs`
4. 저장 후 1~2분 → `https://<계정>.github.io/sinor/prototype/` 로 접속

> 참조 예시(banns0104.github.io/velor-seo 등)와 같은 방식의 정적 페이지 배포입니다.
> 이 프로토타입은 빌드 도구 없이 그대로 호스팅됩니다.

## 주의

- 색·아이콘·최종 카피는 디자인 단계에서 확정하는 **초안**입니다. 구조·콘텐츠 배치 합의가 목적입니다
- 실제 모임명·후기는 **대표 예시**입니다. 실데이터 연동은 개발 Phase 2에서
- AS-IS(현재 앱 화면) 캡처가 확보되면 대비 화면을 추가합니다
