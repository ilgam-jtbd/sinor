분류레벨에이전트 행동
A 이미 되는 것L1즉시 답변 + 딥링크 + 3줄 사용법 · 종결
B 설정으로 되는 것L2바꿀 값 초안(전/후) → 승인 후 적용·로그
C 문서에 답이 있는 것L1근거 구절 인용 · 이견이면 개선 요청 탭으로
D 개발이 필요한 것L2재현 확인 → 이슈 초안 → 승인 후 생성
E 판단이 필요한 것L3답하지 않고 담당자 이관
에이전트가 답하지 않는 것 — 환불·제재·가격 변경·개인정보 문의. 자동화 섹션의 「절대 자동화하지 않는 것」과 같은 선입니다.

그로스 · A/B 테스트 · CRO — 있는 도구로, 싸게

새로 사지 않는 것이 원칙입니다. 실험 배분은 Firebase Remote Config로 처리합니다 — 역컴파일에서 이미 앱에 탑재된 것이 확인됐습니다. SDK를 새로 넣지 않습니다.

먼저 인정할 것 — A/B가 성립하지 않는 구간

웹 7일 427클릭 · 전환 0 수준에서는 결제 같은 저빈도 전환의 A/B가 통계적으로 판정되지 않습니다. 억지로 돌리면 「차이 없음」만 반복됩니다.
지표 성격판정 방법
고빈도 (노출·탭·스크롤·섹션 도달)A/B 가능 Remote Config 배분
저빈도 (결제·상담 신청)A/B 불가 전후 비교 + 미노출 세그먼트 대조 + 정성 관찰 5명
대체 판정을 쓸 때는 왜 A/B가 불가능한지와 대체 방법을 실험 등록 화면에 반드시 적습니다. 빈칸이면 등록되지 않습니다.

CRO 자동화 루프

단계하는 일레벨
① 탐지퍼널 이탈률 악화 감지 → 알림. 자동으로 실험을 시작하지 않음L3
② 가설·변형 초안변형 3안 + 성공지표 + 가드레일 + 표본·기간·롤백 조건L2
③ 배분·모니터링Remote Config 등록 · 50/50 배분 · 매일 상태 갱신L1
④ 판정표본·기간 도달 후 결과 요약 + 권고 · 적용은 사람L2
⑤ 롤백가드레일 악화 시 즉시 원복 후 통지L1
⏸

중간 피킹 금지

최소 표본·기간 전에는 승패를 표시하지 않고 「판정 가능까지 n건 / n일」만 보여줍니다. 막지 않으면 유리한 시점에 멈추게 됩니다.

실험 등록 — 하나라도 비면 반려

가드레일 지표가 비어 있으면 저장되지 않습니다. 「발견은 늘었는데 경험은 나빠진」 상태를 성공으로 읽는 것을 막는 장치입니다.

첫 분기 실험 후보 — 매출 1순위 기준

#대상가설판정
1무통장 미입금 리마인드 문구·시점리마인드가 결제 완료율을 올린다A/B
2홈 수익 카드 3종 위치위치에 따라 상세 도달률이 다르다A/B
3단체미팅 잔여석 표기잔여 강조가 신청 시작률을 올린다A/B
4시럽인연 총액 비교표 위치위로 올리면 상담 신청이 는다전후+세그먼트
5이벤트 배너 상시/기간상시 노출의 피로도A/B + 이탈률 가드레일
무통장 미입금이 1번인 이유 — 현재 결제 누수가 가장 큰 지점이고, 되돌리기 비용이 가장 낮습니다.

운영 가드레일 — 저장 단계에서 막습니다

🚫

앱 유도 금지 구역

시럽인연 상담·여행 결제 페이지에는 앱 유도를 넣을 수 없습니다. 이탈 7.0%의 상담 흐름을 보호합니다.

📱

웹뷰 맥락 자동 분기

앱 내 웹뷰(web.sinor.co.kr)에서는 설치 유도 요소가 자동으로 숨겨집니다.

💰

가격 불일치 차단

상품 DB와 다른 가격은 저장되지 않습니다.

👀

미리보기 필수

실제 화면과 동일한 미리보기를 거치지 않으면 발행할 수 없습니다.

🔤

접근성 검증

본문 17px·터치 48px·대비 4.5:1을 만족하지 않으면 경고합니다.

🧾

변경 이력

누가·언제·무엇을 바꿨는지 모두 기록됩니다.

🧪

실험 가드레일

가드레일 지표가 비면 실험 등록 불가. 최소 표본·기간 전 승패 표시 금지(피킹 차단).

🚀

릴리즈 발행

에이전트는 노트 초안까지. 발행은 관리자 승인 후에만 가능합니다.
