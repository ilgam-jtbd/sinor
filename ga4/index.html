GA4 첫걸음 — 처음이어도 괜찮아요

숫자가 쏟아지는 화면처럼 보이지만, 우리가 볼 곳은 딱 세 군데예요. 이 페이지 하나로 "들어가서, 보고, 확인하는" 것까지 같이 해봐요.

시놀의 GA4 — 로그인하면 이 계정이 맞는지만 확인하세요
접속 analytics.google.com 속성 336035335 측정 ID G-DLK29GEJDF 스트림 웹 1개 (sinor.co.kr)
앱(시놀·시럽) 스트림은 아직 없어요 — 그래서 지금 GA4에는 웹 이야기만 담겨요. (실측 2026-08 · ASO v5.1)
STEP 1 · 개념

GA4가 뭐예요?

한 문장이면 충분해요 — 우리 홈페이지에 누가 와서, 뭘 보고, 뭘 했는지 기록해 주는 구글의 무료 장부예요.

가게로 치면 이래요. 문에 달린 손님 세는 센서(방문자 수), 손님이 어느 매대 앞에 오래 서 있었는지(어떤 페이지를 봤는지), 그리고 계산대 장부(신청·결제 같은 행동)까지 한 권에 적히는 거예요.

외울 건 하나예요 — GA4는 모든 걸 "이벤트"라는 단위로 적어요. 페이지를 봐도 이벤트, 버튼을 눌러도 이벤트, 결제를 해도 이벤트. "무슨 일이 있었다"의 한 줄 기록이라고 생각하면 끝이에요.
STEP 2 · 실습

오늘 10분 — 이것만 해보세요

아무것도 바꾸지 않아요. 보기만 하는 연습이라 실수할 게 없어요.

  1. 1

    로그인

    analytics.google.com에 회사 구글 계정으로 들어가요. 왼쪽 위에서 속성이 336035335인지만 확인하세요.

    ✓ 계정이 안 보이면 → 권한 초대가 필요한 것 — 개발팀(우종선님)께 요청
  2. 2

    실시간 화면 열기

    왼쪽 메뉴 보고서 → 실시간. 지금 이 순간 사이트에 몇 명이 있는지 나와요. 휴대폰으로 sinor.co.kr을 열어보세요 — 숫자가 1 올라가면, 측정이 살아있는 거예요.

    ✓ 이게 GA4에서 제일 재미있는 화면이에요
  3. 3

    어제 하루 둘러보기

    보고서 → 참여도 → 페이지 및 화면을 열고, 오른쪽 위 기간을 "어제"로. 사람들이 어제 어떤 페이지를 많이 봤는지 순위로 나와요. 칼럼·단체미팅·시럽인연이 보이면 정상이에요.

    ✓ 여기까지 되면 오늘 목표 달성!
STEP 3 · 루틴

매일 아침, 이 세 화면만 보면 돼요

GA4 메뉴는 수십 개지만 다 볼 필요 없어요. 시놀에 필요한 건 세 개예요.

① 실시간

지금 몇 명이 와 있나. 유튜브 발행이나 광고를 켠 날, 효과를 즉시 볼 수 있어요.

보고서 → 실시간

② 어디서 왔나

검색으로 왔는지, 광고인지, 유튜브인지. 시놀은 검색이 57%로 가장 커요.

보고서 → 획득 → 트래픽 획득

③ 뭘 봤나

어떤 페이지가 인기이고 어디서 나가는지. 단체미팅 페이지가 이탈 12%로 최고 성적이에요.

보고서 → 참여도 → 페이지 및 화면
시놀의 "정상 범위"를 기억해 두세요 — 최근 28일 기준 활성 사용자 약 5,750명, 검색 유입 57%, 단체미팅 이탈률 12%, 시럽인연 상담 페이지 이탈률 7%. 이 숫자에서 크게 벗어나면 그때 살펴보면 돼요. (출처: 정합기준 정본 2026-08)
STEP 4 · 시놀 현안

지금 GA4가 못 보고 있는 것 — 같이 고쳐요

GA4 자체는 잘 돌고 있는데, 중요한 순간 몇 개가 기록에서 빠져 있어요. 최지영님은 "고치는 사람"이 아니라 "고쳐졌는지 확인하는 사람"이면 충분해요.

왜 급하냐면요 — 결제가 7개월간 20건만 기록됐어요(실제 매출 규모 대비 극히 일부 — 무통장 입금이 안 잡히는 걸로 추정). 네이버 광고는 7일간 75,922원을 썼는데 전환 기록이 0이에요. 이대로면 뭘 바꿔도 좋아졌는지 알 수 없어요.

  • 결제 완료가 GA4에 찍히게 하기 — 카드·무통장 둘 다 (개발 작업 · 완료되면 실시간 화면에서 테스트 결제로 확인)
  • 상담 신청·단체미팅 신청도 이벤트로 찍기 (개발 작업)
  • 사이트 안 검색어 수집 확인 — 회원들이 검색창에 뭘 치는지(월 4,232명!) 보이게 (관리 → 데이터 스트림 → 향상된 측정에서 "사이트 검색" 켜짐 확인)
  • 구글 서치콘솔 연결 — 무슨 검색어로 들어오는지 보이게 (개발과 함께)
  • 앱(시놀·시럽) 스트림 추가 — 앱 설치·앱 안 행동도 GA4로 (개발 작업 · ASO v5.1 §11 참고)

개발 쪽 상세 항목은 키워드관리 요구서 v1.0 §8 점검표에 이미 정리돼 있어요. 최지영님은 위 체크리스트가 하나씩 ☑로 바뀌는지만 챙겨주시면 돼요.

STEP 5 · 설정 한 가지

"주요 이벤트" 3개만 지정해요

GA4에게 "이 세 가지가 우리한테 제일 중요해"라고 알려주는 거예요. 그러면 보고서 곳곳에서 이 셋을 기준으로 보여줘요.

주요 이벤트로 지정할 것왜
상담 신청 (시럽인연)매출의 절반이 여기서 시작돼요
단체미팅 신청사이트에서 구매 의도가 가장 높은 흐름이에요
결제 완료 (purchase)최종 성과 그 자체

지정 방법 — 관리(왼쪽 아래 톱니바퀴) → 이벤트 → 목록에서 해당 이벤트 오른쪽 스위치를 켜면 "주요 이벤트"가 돼요. 클릭 두 번이면 끝이에요. 단, ④의 개발 작업으로 이벤트가 먼저 찍히고 있어야 목록에 나타나요 — 그래서 순서가 "개발 부착 → 최지영님 지정"이에요.

STEP 6 · 곧 쓰게 될 것

유튜브 발행이 시작되면 — 효과 보는 법

발행킷의 링크에는 꼬리표(UTM)가 붙어 있어요. 그 꼬리표 덕분에 "이 영상에서 몇 명이 왔는지"를 GA4에서 바로 볼 수 있어요.

  1. 1

    트래픽 획득 화면 열기

    보고서 → 획득 → 트래픽 획득

  2. 2

    표 위 기준을 "세션 캠페인"으로 바꾸기

    표 첫 열의 작은 화살표를 눌러 세션 캠페인을 선택해요.

  3. 3

    영상 이름표 찾기

    fortune-202609, meet5060-202609 같은 이름이 보이면 — 그게 각 영상에서 온 사람들이에요. 몇 명이 왔고, 얼마나 머물렀고, (이벤트가 붙은 뒤엔) 신청까지 했는지 나와요.

좋아졌는지 볼 땐, 이것도 같이 봐요 — 새 유입이 늘어도 시럽인연 상담 신청 수나 단체미팅 신청 완료율이 줄면 성공이 아니에요. 페이지가 느려졌다는 문의가 늘어도 신호예요. "늘리려는 숫자"와 "지키려는 숫자"를 항상 짝으로 보는 것 — 이게 시놀의 규칙이에요. (정본 §9 가드레일)
